# 分组、持仓与行情提醒

## 使用方式
- 自选表格顶部可新建分组。“全部”永久存在，直接添加与其他分组股票均在其中去重展示。
- 在自定义组中添加股票会同时加入“全部”；也可以通过“从全部自选加入当前组”引用已有股票。
- 自定义组的“移出”不删除全局股票。全部自选中的删除需确认，并清理该股票的分组关系、持仓和提醒。
- 主页面与悬浮窗共用当前组。**只监控当前组**，设置过提醒的其他组股票不会额外请求。
- 设置 → 悬浮窗可配置上一组/下一组全局快捷键；输入组合键，留空保存停用。切组时悬浮窗短暂显示组名。

## 持仓
- 点击表格“成本价”列中的“设置持仓”录入每股成本及股数。
- 成本最多四位小数，股数必须是非负整数，不强制整手。
- 空成本和零成本不同：零成本可计算盈亏金额，但收益率无定义。
- 持仓跨组共享；市值、浮盈和收益率由最新可用行情计算，不包含未录入的交易费用、分红或已实现盈亏。

## 提醒
- 双击股票、右键“设置行情提醒”，或选中行按 Enter 打开逐票弹窗。
- 涨跌幅按昨收价计算。`5` 表示上涨达到 5%，`-5` 表示下跌达到 -5%。规则保留，每日触发计数重置。
- 固定价格规则长期保留，向上/向下穿越都可触发；跳过目标价也算穿越，同一价格不连续重复。
- 每种规则有独立开关，可选择每日一次、重新穿越或冷却间隔（1–1440 分钟）。
- 涨跌幅冷却模式：条件持续成立时，每个冷却期最多一次。价格冷却模式：同时要求出现新的穿越。
- 总开关只暂停通知，不删除逐票规则。规则和去重状态写入 SQLite，缓存恢复不触发通知。切入一组后的首个有效报价用于建立观察基线。
- Windows 使用应用自身 AUMID `com.chinesecanfly-wxy.bull-arrives` 发送原生通知；主窗口保留本次运行最近 50 条记录，可在记录弹窗中清空。系统返回“已受理”不代表横幅一定可见，勿扰或企业策略仍可能隐藏横幅。
- 绿色版首次使用时，请在设置 → 提醒中由用户主动点击“启用 Windows 通知”。程序只为当前用户通过 Windows Shell COM 创建本应用开始菜单快捷方式，不需要管理员权限，不冒充 PowerShell，也不会修改系统通知/勿扰策略；程序移动后可点击修复。
- 默认原生发送失败时自动使用不抢焦点的独立桌面提醒窗；若系统已受理但看不到横幅，可启用“同时显示桌面提醒”。设置中的测试通知与真实行情提醒使用同一通知路径。

## 时段与窗口
- 默认北京时间工作日 09:15–11:30、13:00–15:00，包含开盘集合竞价；结束时刻不再发起请求。
- 设置 → 行情可编辑多个时间段和额外休市日期。**目前只内置周末判断，未附完整交易所节假日日历；节假日应在休市日期中配置。**
- 非允许时间不主动拉取股票/指数及详情、搜索行情；现有缓存仍可显示，详情无缓存会明确提示暂停。
- 默认主窗口 1000×680 逻辑像素；可选择固定打开大小或记住上次大小。
- 本轮已移除主页面右下角邮箱和进群入口。
