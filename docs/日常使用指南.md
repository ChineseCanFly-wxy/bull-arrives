# 日常使用指南

研究中心默认“简化版”，打开后查看自动模型交易与各模型账户。资金和账户配置统一在“模拟账户”管理：启用本地历史服务后，程序在A股交易日09:00更新数据，成功10分钟后检查已有冻结模型，有合格候选时独立建账、选股、买卖和记录成交。日常无需选择模型、来源或交易账户，也无需逐笔确认；保持应用运行即可。研究中心“提醒与记录”统一控制提醒，账户卡可直接切换持仓、打开模拟账户配置，或暂停、删除某个模型。手动条件提醒单独使用，不需要账户、不自动交易。切换“深入研究”可查看历史回放和技术研究。

## 跟着原模型操作

先打开“模拟账户”设置新自动模型账户的初始资金，默认每个账户10万元；之后出现新模型机会时，使用当时保存的预设。修改预设只影响后续新账户；已有账户的资金需在所选账户单独调整，按差额增减现金并留下记录，保留持仓和成交。持股上限、仓位与入场退出配置也在所选模拟账户管理。各模型沿用已有研究分别推荐2/3/3/5/2只，上限可设1—10只；排序模型5只沿用每票10%、总预算50%的模拟配置，其他模型使用原8%入场基准。不同模型资金与账本相互独立。

程序按原模型已完成日信号和各自执行条件自动提交委托，记录股票、股数、限价、原因和有效期，新盘口满足条件后才模拟成交。没有合格候选或资金不足买一手时，新模型不创建空账户；已有模型持续复用原账户，不重置资金和持仓。同一天已完成的模型检查、已有同模型账户和同股票的重复买入都有去重约束；重启不会重复创建。用户暂停、删除的模型会持久记住，不因后续自动检查重新建账或恢复。

研究中心日常只需看账户概览、持仓、待成交委托和最近成交。“暂停提醒”只静音，自动买卖继续；“暂停自动买卖”保留账户和持仓并撤销未成交委托；“删除模型”会先展示专属账户、持仓、订单等清理范围，确认后只删除此专用模拟账本。手动操作和其他策略不能使用自动模型专用账户，过户费和滑点为0。原模型研究收益仍保留历史研究费用，不等同于当前账户收益。原证据和采用依据可在折叠的研究详情查看。

各模型还独立研究入场与提前退出。大盘模型最多3只时，原信号外还须满足沪深300近5日上涨、处于60日均线上方或等于均线、个股站上10日均线，才尝试买入；条件未满足时可以空仓。其他数量恢复原执行，页面注明时点研究不适用。展开“本模型入场与提前退出研究”可看9套方案及未采用原因；20个交易日是最多计划持有，可因原风险条件更早退出。多年累计收益与每笔持有期限分别查看。

当前五个自动模型使用“完成日线产生信号、下一交易日09:30—09:35实时盘口买入”的方式：有盘中成交，但没有盘中才产生新买入信号的已验证策略。账户直接显示信号时钟与执行说明。后台晨间筛选只接收这五个已登记的日线模型；未来盘中信号模型须单独验证和接入自己的调度，不能混进日线晨间入口。

盘中继续从行情源读取报价与盘口。盘后16:00起优先获取StockDB完成日日线，近期相邻缺口自动尝试新浪/腾讯；原模型更新失败会自动重试。模拟跟踪顶部“模型行情数据”显示应到日期和来源。开启本地历史后默认在A股交易日北京时间09:00后台更新StockDB，周末和法定休市日不执行；交易日晚启动且当天尚未执行时补做一次，当天执行后不重复。成功后再等待10分钟，后台检查模型并准备专用账户。顶栏“更新数据”和深入研究的“更新历史数据”均保留，手动更新也允许休市日执行。手动与定时更新都会自动停止已核实的本地StockDB、更新并恢复服务；外部启动的同一引擎保留原启动配置，更新失败也尝试恢复，无需先手动退出。每个交易日只自动执行一次；失败、超时或异常中断后不自动重试，重启应用也不重复。失败原因保留在数据状态和自动操作记录，可手动更新或等待下一交易日。缺行情的定时弹窗和开关已移除；行情未齐备时保留状态与原因，模型等待，已有持仓保留，错过窗口不补成交。跨多日未留存缺口仍需兼容历史数据，应用需保持运行。

## 日常筛选的最短流程

1. 打开“市场筛选”。首次使用为“不限条件”，之后恢复上次停留的页签、条件和名称。
2. 点一个常用预设，或展开“自定义条件”。预设只填写条件；点击顶部“查询”才真正读取行情。
3. 查看价格、涨跌幅、成交额、行业与概念。点行内“分析”打开个股研究，点“走势”看行情，点“+自选”加入自选。
4. 想比较强弱时点“本页评分”，或点“全部量化评分排名”。评分开始前显示“未评分”；全量会对本次查询命中的股票分批计算，完成后按技术分排名。可随时停止，停止后明确标为部分评分。
5. 常用条件点“另存为”保存名称；选中“我的条件”后，可覆盖条件、改名或删除。改名只改名称，不把当前未保存的修改覆盖进去。

顶部切换、查询工具条与底部分页固定，滚动内容时一直可用。更改条件、数据源或每页数量后会标记“待查询”，已有结果仍属于上一次查询，翻页也继续使用上一次已提交条件。重新查询会清空旧评分；重新打开页面也不自动恢复评分。

全量排名优先读取本地 StockDB 历史，不会自动调用 AI。本地历史缺失的股票显示失败原因；陈旧历史、未知截止日和不同截止日分数显示边界，不参与同日排名。行业与概念字段由行情通道提供，缺失时显示“暂无”并提示数据来源。

量化评分是现有技术因子的加权状态分，不是上涨概率，也不代表已有多年盈利验证。预设仅用于缩小观察范围；冻结模型证据在“研究模型”及研究中心查看。ST、北交所、退市股等继续排除。

## 最简单的模型条件选股

1. 打开“市场筛选 → 研究模型”，选择“全部已注册模型（5）”或其中一项。页面会恢复选择和已保存的结果；切换选择不计算。
2. 点“筛选符合条件的股票”。后台先核对StockDB最近完成日，近期相邻缺口尝试新浪/腾讯，合格后再运行原冻结模型推断；可以关掉页面。进度和结果在数据库保存，重新打开能接着看。
3. 每个模型各自排序，查看命中依据、冻结日价格与分数。结果行可以“分析 / 走势 / +自选 / 观察”。名称源缺失时展示代码；不同模型的分数单位不同，不跨模型合并胜率。
4. 点“观察”，选择“模型新命中/失效”“模型＋实时条件确认”或“模型＋主线＋实时条件确认”。默认勾选同时开启该模型盘后自动更新：复用或准备纸上账户，应用运行且完成日数据齐备时推进。
5. 在研究中心开启独立研究提醒；主线组合需先在板块主线页完成扫描。已有模型命中加入时静默登记，新确认或失效时提醒。自定义涨跌幅条件需要交易时段的新鲜报价；休市、缺数据或未核验主线显示等待。到“资讯与提醒 → 研究提醒”点击“触发条件证据”，读取触发当时保存的模型、实时涨跌幅、主线及来源。旧的分钟确认预设和组合已停用，历史提醒记录保留，可删除或从筛选结果重新添加可用条件。

若StockDB暂时断开，只有本地快照及指数截止日期已达到最近完成日才允许备用，页面会注明未在线核对；日期落后时停止最新筛选并提示更新。旧结果保留为历史，不显示成当前候选。当前五项均为已注册研究模型，没有实盘准入，筛出股票不代表下一开盘一定可买入。

研究中心“深入研究 → 模型模拟”提供后台任务记录，可以取消和续跑。续跑只跳过输入版本相同且已核验的步骤；账户与断点一起保存。点“比较本模型：基准 / 15日 / 双费”可完成三项独立多年账本对照，结果可点开账本；这项改变执行参数，不会训练新模型。

## 个股分析与 AI 解读

打开分析后先看技术状态分和简短模型观点；模型详细证据、近期原文、AI 解读、技术形态与规则对照默认收起。

1. 需要核对时展开“模型证据与近期原文详情”，看冻结模型版本、多时期表现、个股对应评分、公告时点与采集范围。
2. 展开“AI 解读”，点击“生成 AI 解读”才调用 Claude。仅展开、换股、打开页面都不会自动生成。结果回答“现在怎么看、依据是什么、还差什么条件、什么会推翻判断”，每条判断附本次快照的数值和日期。
3. 有具体疑问时展开“针对性提问、提示词与调用记录”。连续对话和终端位于高级折叠区。
4. “技术形态与规则对照”保留趋势、超跌、突破三条规则的状态和价格情景，列出本股回放门禁与多年验证边界。本股回放通过不等于多股多年策略有效。

圆形问号在鼠标悬停或键盘焦点进入时显示提示，移开后关闭；按 Escape 只关闭当前提示，不会把说明文字展开到页面中。

## 不经过主页面操作，直接打开设置

应用保持运行时，右键系统托盘的 Bull Arrives 图标，可直接进入研究中心、市场主线、市场筛选、模拟账户，以及一个统一的“设置”入口。应用会恢复窗口并直接打开对应页面。

在应用顶部功能按钮上右键，也能打开相同的快捷入口。顶部按钮统一为图标加中文名称，窗口较窄时可横向滚动。设置分类之间切换保留草稿；离开设置时正在保存会阻止切换，未保存内容会要求确认是否放弃。

## 悬浮窗：加自选后自动展示

右键悬浮窗有两个入口：“快速自选”与“展示设置”。快速自选与旁边“＋”号相同，可以添加、删除当前分组自选；展示设置直接打开悬浮窗分类。

在展示方式里选择“自适应全显”：当前分组加多少显示多少，增删后自动调整高度；超过屏幕可用高度时滚动查看。需要小窗轮播时选择“轮播”，每页可设1—20只。原来保存的固定模式自动使用自适应全显，无需重新保存。

## 怎样收到自动买卖提醒

1. 在“模拟账户”保存新自动账户的资金预设，保持本地历史和自动交易开启；研究中心直接查看后台检查进度与已有账户，无需逐个选择模型、绑定来源。
2. 保持提醒开启。实际模拟成交后会通知账户、股票、买卖方向、股数、价格和北京时间；信号和未成交委托不称成交。暂停提醒只静音，暂停自动买卖才停止新交易。
3. 保持应用运行即可，盘后更新模型，盘中按模型计划与实时盘口执行，不需要每天手动筛选、观察或确认。关闭页面或缩到托盘可以继续；真正退出后在下次启动核对数据及计划，错过窗口不补造成交。

手动观察在“手动条件提醒”页独立使用，无需交易账户，不下单。清单每条支持“删除”，删除或修改不影响自动模型的候选池和所需日线维护；旧已暂停记录可删除或重新从该股筛选结果点击“观察”。统一研究提醒开关涵盖自动成交、手动条件和主线研究；每条消息标明自身用途。

## 资讯通知与自动操作记录

打开右下角“资讯与提醒”：

- **市场资讯**：开启资讯采集后，只通知本次启动之后发布且时间有效的内容。启动前的消息和发布时间未核实的消息可以留存原文，不会补弹通知；重启会重新计算起点，首次开启采集仍先建立当前水位。
- **自动操作**：查看后台数据更新、模型检查与建账、模拟买卖、主线扫描和自动研究的进度、结果与失败原因。列表包含时间、来源和状态，最新记录在前，连续相同内容合并显示次数；可以搜索或清空。
- **记录自动操作**：独立开关，默认开启，保存后重启仍记住选择。关闭只停止新增页面记录，不停止自动任务，也不影响买卖或资讯通知；重新开启不会补记关闭期间的操作。关闭面板仍可记录，再次打开会读取最新结果。

自动操作记录只保留本次运行最近200条，重启后清空；不会额外弹出系统通知。原有程序诊断日志继续保留。

## 找市场主线

顶部“市场主线”独立打开，点击“开始全市场扫描”一次即可：程序分批扫描并保留进度，关闭页面或缩到托盘继续；点击“暂停全市场扫描”会停止正在进行的自动扫描，之后“继续”从已保存进度恢复。全目录完成后等待下一个已完成交易日的新行情，不循环重复扫描同一天；有失败时主动继续可重试本轮。

继续时只补查失败和未完成板块，成功候选、原处理进度和补查游标保留。东方财富板块按同一BK代码尝试官方备用网关、限定日期与宽窗口；全部66个真实指数交易日可核验后才比较强度。备用源也缺历史时，保留具体日期、覆盖数与来源原因，不换板块、不填价；已成功结果仍可查看。

默认按20日相对沪深300强度排序，可切换60日查看。强势且距离均线超过2ATR的板块仍留在榜上，标记“趋势强·等待回落”，强度排名不等于可以买入。点板块查看领涨观察，个股默认展示10只，可在详情右侧“展示数量”选择3、5或10只，程序记住选择；数量不足时只展示实际合格个股。此设置只影响展示，观察条件和通知中的前3只候选保持不变；即使少数成分缺数据，通过个股日期、趋势和风险核验的候选仍显示，并注明覆盖未全和缺失原因。整板块尚未通过完整覆盖时，不确认全市场最强或发出通过完整核验的主线提醒。

在板块详情里，领涨观察股先展示股票与强弱数据；每只股票的“参考买卖策略”默认收起，点击后才显示该股的点位、持仓成本输入和同日模型核对。已删除重复的“原始分层计划”参数表，原始研究数据保留。参考策略包括：回踩入场区、前高突破确认区、MA20弱化线、盈利保护启动线及风险退出线。沿用已有MA20/ATR/前高研究计划；入场区仍须止跌与完成分钟量价确认，触价本身不代表应买卖。盈利保护参考是成本＋2×ATR，风险退出参考是成本－3×ATR；持有5—20交易日内复核，趋势失效可以提前退出。

已经持仓时，在该股“我的持仓成本”填写实际成本，程序重算保护与退出参考线；留空时明确用该截止日收盘价演示，没有读取或修改账户。价格从复权指标换算到对应日未复权报价。缺少有效原始价格、指标或日期时不编造点位；板块未完全确认、超过24小时未刷新、历史快照或主线条件不通过时分别注明待确认或只供旧结果参考。数值只用于手动策略参考，未完成多年主线可交易收益验证；不自动下单、不实时监测这些点位，也不新增买卖点通知。

详情的“开启主线提醒”只做盘后观察通知，不下单，也不使用自动模型账户。页面显示行情截止日、成分覆盖、指数来源和缺失原因；休市期间使用最近已完成交易日，例如2026年10月5日显示2026年9月30日。可回看最近14天实际留存的提醒快照，缺日期不使用当前结果替代。当前成分不是历史时点成分，不能据它还原任意历史阶段最强股票。

新增主线历史研究比较了31个行业、2018年至2026年9月30日、5种预先登记的窗口与持续性规则，以及5/10/15/20交易日前向指数表现。对照未证明替换原20/60日默认更稳，因此保留默认；这些是行业指数观察研究，不是个股组合可交易收益，也不会改动现有冻结选股模型。证据见[2026-10-05研究结果](../research/ashare-mainline-2026-10-05/RESULTS.md)。

## 先看哪些结果

先看数据截止日期与样本数，再看扣费收益、最大回撤、完整持仓周期和买卖理由。收益率高但样本少、回撤大或数据过期时，不能仅按收益判断好坏。没有符合条件的股票时保留空名单，不降低阈值凑股票。

## 深入研究：每个功能怎么用

日常自动买卖留在“简化版”管理。盘后AI研究用于历史对照，日常建议保持关闭，不影响原模型自动买卖和已开启的成交提醒。独立的候选股分钟走势确认已移除：它未完成实时分钟数据接入，也没有独立的多年分钟交易验证。深入研究用来核对数据、验证已有模型、查看研究依据；打开页面、切换模型、读取结果不会启动计算。研究操作保留三个主要入口；研究提醒、任务进度与实验资料集中在“提醒与记录”，其他页面不重复展示。

第一次操作：进入“数据准备与更新”检查服务与路径 → 到“冻结模型回放”选择一个已有模型 → 点“运行真实多年回放” → 自动切到“提醒与记录”看任务进度 → 完成后点“查看账本” → 最后到“研究证据”核对历史依据。已有结果直接点账本，不需要重复计算。

### 数据准备与更新

作用：检查本地历史是否可读、截止日期是否合适，以及模型回放需要的程序和文件是否齐全。

1. 没配置时点“自动查找”，选择找到的程序，或“浏览 stockdb.exe”；再点“启用并启动”。已经连接时点“测试历史连接”即可。候选按钮只是选择程序，不等于启动回放。
2. 要补历史时先“选择 数据更新.exe”，再点“更新历史数据”。程序会暂停已确认的本地服务，更新后恢复；手动按钮保留，休市日也可手动执行。
3. 第一次回放或换电脑时，展开“本机研究环境与数据路径”，核对下面四项并“保存路径”。已有正确配置不必每天重填。
4. 看上方连接状态、样本截止日期与失败原因；准备好后点“数据就绪，查看冻结模型回放”。单只样本检查不能证明全部模型输入齐全，运行研究还会核验完整文件。

| 配置 | 选择什么 / 什么时候改 |
| --- | --- |
| 项目目录 | 包含 research/research-center-runner、冻结模型和研究文件的项目根目录，不是安装程序目录。 |
| Python可执行文件 | 已具备原模型依赖的 python.exe。首次运行或研究环境变动时调整，不自动安装依赖。 |
| 兼容快照目录 | 原模型使用的行情快照目录，不是单只股票文件。 |
| 显式CSI300 NDJSON | 原研究输入的沪深300指数文件，用于交易日和指数条件核验。 |
| 非默认服务地址 | 只有地址或端口变动时展开，填写实际地址并“保存并测试”；普通本机保留默认地址。 |

数据更新本身不下单；已开启的用户模型账户仍由自己的交易流程管理。

### 冻结模型回放

作用：用已经研究好的模型核对多年历史中的累计扣费收益、回撤、持仓周期和买卖原因，不训练新模型。

1. 点一个模型卡片，只选择模型；卡片下面的短句解释它主要判断什么。
2. 第一次保留“原20日期限＋3ATR失效”，点“运行真实多年回放”。15/20日是研究执行的持有上限，可因失效等条件更早退出；涨跌停、停牌或权益限制也可能导致无法按时卖出。
3. 在“提醒与记录”的“研究任务与已核验结果”看进度；关闭页面后应用仍运行时继续，彻底退出应用会中断，重开后可“继续未完成项”。
4. 完成后点“查看账本”，或点下方“信号来源与历史回放账本”的一条记录。每条账本有自己的数据截止日、模型身份和执行对照。
5. 先看累计净收益与最大回撤，再看完整持仓周期、未平持仓和“最近实际回放成交”的执行原因。数据指纹与限制需要追查结果来源时再展开。

累计净收益是整个研究区间扣费后的盈亏，不是年化收益或单只股票胜率；最大回撤是净值从阶段高点跌落的最大幅度；完整持仓周期只算已卖完的记录。未平股票、权益锁定、未到账股息和超期尾部应一起查看，不能只凭收益数字判断正常执行。研究账本与“模拟账户”中的用户账户分别记账。

| 执行对照 | 有什么用 / 怎么用 |
| --- | --- |
| 原20日期限＋3ATR失效 | 原模型的基准执行口径，首次保留默认再回放。 |
| 同模型15日期限 | 将持有上限改为15日作对照；仍用原20日预测标签，不重新训练。 |
| 原20日双成本 | 将原研究费用翻倍，检查更高费用下的表现。 |
| 分层执行反证 | 查证同时改变入场、减仓和退出是否有效；已有失败结果，不作为默认执行。 |
| 已核验权益日期 | 用已核验的送转上市日及股息到账日修正已知记账问题，其他未核验权益仍保留挂起。 |

### 期限、费用与前向来源对照

展开回放页同名区域，按需要使用以下按钮：

| 功能 | 有什么用 | 怎么操作 / 结果在哪里 |
| --- | --- | --- |
| 比较本模型：基准 / 15日 / 双费 | 用同一模型与输入检查持有上限及费用的影响。 | 先选一个模型，再点击；固定计算这三项，逐项保存账本。到任务区逐个“查看账本”，比较相同截止日的收益、回撤与成交。 |
| 建立前向信号来源账本 | 从启用时点起核对后续新完成日的模型信号，为后续日线信号核对及原模型自动跟随提供来源。 | 选模型和对照后点击；完成后选中新的“前向观察”账本。没有新行情时保留现金并显示等待，不回填启用之前的买卖。 |
| 按新快照延续来源账本 | 手动检查新增完成日，继续所选的研究记录。 | 选一条前向账本后点击，在任务区看结果，原模型、对照与账本身份保留。 |
| 开启 / 暂停盘后更新 | 让选定的前向研究账本自动检查完成日。 | 选前向账本，点“开启盘后更新”，保持应用运行；要停点“暂停盘后更新”。数据不足时等待，只影响该来源账本，不暂停用户模型账户。 |
| 导入可信模型账本 | 查看在同一可信研究程序中已经生成的账本。 | 选择对应JSON，模型身份、来源和损益核验通过后进入下方账本。不能拿普通表格或模拟账户文件替代。 |
| 最新完成日模型观察 | 查看该研究账本在完成日符合固定模型阈值的股票。 | 选账本后查看股票、原预测、阈值与现金参考股数；无候选保持空表。参考股数不是已成交数量，用户成交在自动交易账户查看。 |

### 研究证据

作用：查看模型为何得到当前研究结论，核对多个阶段、数据范围和失败对照。

1. 点击“研究证据”，先看“策略比较”：对比训练、验证、已观察后段的累计净收益、回撤、成本压力和同池基线。不同阶段分别记账，不能直接拼成复利。
2. 切到“数据覆盖”，核对起止日期、股票与样本数量、数据来源、缺失项和版本指纹；指纹相同只证明内部内容对应，不能证明数据真实或模型获准。
3. 切到“实验与压力”，展开具体结果，查看延迟、费用、执行规则等反证。失败配置保留，帮助判断哪些改法不能采用。
4. “刷新证据”只重读已保存资料，不重新回测。拿到该研究程序生成的研究证据JSON时，才使用“导入研究证据包”；它与回放页的“模型账本JSON”用途不同。

查看、刷新和导入研究证据不创建交易账户或订单，也不会将模型自动变为可用策略。

### 研究任务与已核验结果

位置：简化版、深入研究均通过同一个“提醒与记录”入口查看。作用：看后台实际进度、失败原因和已保存结果。运行研究后自动切到这里并展开任务；切换到其他页面，任务继续，进度与已核验结果保留。

1. 点一条任务，查看类型、执行阶段、完成步骤与消息；“刷新”只读取状态。
2. 不想继续本次计算时点“取消”。取消当前工作并保留已核验结果，不删除用户账户；要停止用户模型交易，去简化版的模型账户操作。
3. 中断、取消或失败后，先处理显示的数据/环境问题，再点“继续未完成项”。只跳过输入版本相同且已核验的步骤，输入发生变化时会拒绝跨版本续算，应保留旧结果并新建任务，不把旧结果冒作新结果。
4. 点击已完成结果中的“查看账本”，跳到对应回放记录。组合实验任务显示自己的年度结果；查看已有结果不再次计算。

## 研究资料与实验记录（可选）

进入深入研究的“提醒与记录”，下方只有一个默认收起的资料区。展开后，每个子项都有用途、操作和结果说明；没有实际记录的旧账本、任务书不显示。

| 功能 | 有什么用 | 怎么操作 / 结果在哪里 |
| --- | --- | --- |
| 技术组合实验记录 | 核对固定技术组合跨年份、双费、延迟与同池对照是否稳定。 | 先读数据前提，按需点“运行五年技术组合研究”；在任务区看进度，完成后查看年度结论、选择规则及研究账户。结果不自动加入原模型列表。 |
| 扩展实测 | 查看TSP规则、多日形态、财务增量37及数据衔接/权益记账核验。 | 展开一个研究，先读结论，再展开收益回撤对照及数据局限；展开页面会读取已有报告，状态定时刷新，不重跑研究。用于了解失败原因和已检验的改法。 |
| 旧模拟账本 | 追查早期实验的账户、成交、冻结条件与失败原因。 | 点左侧一条旧实验，右侧看曲线和最近模拟指令；需要时展开成交证据和冻结条件。仍运行的旧实验可“暂停原实验”，保留账户、持仓与记录。 |
| 已登记的研究任务书 | 查看某次研究想验证的假说、反证条件与缺失数据。 | 展开一条任务；要复核点“选择该任务的可信配置”，只选好模型和对照，仍需到回放页手动运行。 |
| 盘后AI研究设置 | 按需登记新假说并运行可信的已有模型对照。 | 日常自动买卖不需要开启，默认关闭。确实需要继续研究时，先“配置AI连接”并测试，再勾选启用并“保存自动研究设置”。应用运行时在交易日16:00后、22:00前最多尝试一次：先补做已有任务书的历史对照，无待验证任务时才调用AI提出假说，再用已有冻结模型核验。结果看本页最近研究消息、任务书与回放账本；停用要取消勾选再保存。AI调用可能产生服务商费用；同配置完成后不重跑，同日失败保留原因，不循环调用，不自动采纳新模型或创建交易账户。 |
| 研究提醒与通知测试 | 控制研究消息是否推送，检查系统与应用提醒是否能收到。 | 只在“提醒与记录”设置研究提醒，“暂停/恢复提醒”只切换消息；展开“通知测试与帮助”，点“测试研究提醒”发送一次测试消息。未收到时看“通知帮助”和返回状态，按需启用或修复Windows通知身份。不会暂停计算或模型买卖。 |

已删除重复入口和未形成可用结果的空操作区，原始研究文件、冻结研究账户和账本保留。在股票“观察”中自定义组合是观察逻辑，需要继续命中原模型；缺少证据保持未知。

设置与数据准备显示正常盘符或网络共享路径，可以查看、复制完整地址；Windows内部路径前缀只在展示时隐藏，浏览选择、保存和实际启动继续使用原始路径。后台刷新不会重复切换按钮加载图标；当前账户与持仓保留，手动刷新也保持按钮尺寸，读取失败会保留上次结果并显示原因。
