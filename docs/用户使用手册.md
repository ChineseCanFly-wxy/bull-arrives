# QuantDesktop 用户使用手册

> 本手册依据当前版本界面与实际功能编写，适用于 Windows 上的 QuantDesktop。行情与提醒依赖第三方公开数据源和本机通知环境，仅供行情观察，不构成投资建议，也不承诺数据、通知或更新在所有网络和系统环境中始终可用。

## 1. 开始使用

### 1.1 绿色版启动

1. 将压缩包**完整解压**到一个普通、可写的文件夹，不要直接在压缩软件中运行。
2. 确认 `quant-desktop.exe` 同级存在 `portable.dat`。程序以此文件判断是否进入便携模式。
3. 双击 `quant-desktop.exe`。
4. 若程序无法显示、出现空白窗口或系统提示缺少运行组件，请安装或修复 **Microsoft Edge WebView2 Runtime** 后重试。QuantDesktop 的界面依赖 WebView2；是否已预装取决于 Windows 环境。

目录关系示例：

```text
QuantDesktop/
├─ quant-desktop.exe
├─ portable.dat
└─ data/                  # 首次运行后自动创建
   ├─ quant-desktop.db    # 自选、分组、持仓、提醒和设置
   └─ quant-desktop.log   # 运行日志
```

- 有 `portable.dat`：数据写入程序同级的 `data/`，设置中的运行模式显示“便携模式”。
- 没有 `portable.dat`：按标准安装模式运行，数据写入当前用户的 `%APPDATA%\quant-desktop\`。
- `portable.dat` 只是模式标记，不能代替 `data/` 中的实际数据。
- 绿色版不会自动检查或安装更新，底部和托盘中的“检查更新”入口也会隐藏。

### 1.2 绿色版升级与备份

升级前建议按以下顺序操作：

1. 在托盘图标右键菜单中选择“退出”，确认程序已经完全退出；只关闭主窗口不会退出程序。
2. 复制并备份旧版整个 `data/` 文件夹，至少保留 `data/quant-desktop.db`。
3. 解压新版本，并确认新目录中仍有与新 `quant-desktop.exe` 同级的 `portable.dat`。
4. 将旧版 `data/` 整体复制到新版本目录，再启动新版本。
5. 核对自选、分组、持仓、提醒和设置后，再决定是否删除旧目录及备份。

不要在程序运行时复制数据库，也不要在覆盖升级时误删 `data/`。若直接移动绿色版目录，Windows 通知快捷方式可能仍指向旧路径，处理方法见“8.2 Windows 通知身份”。

标准安装版可在主界面底部或托盘菜单手动“检查更新”。发现更新后按界面提示下载、安装；交易时段内，启动检查不会主动弹出更新提示，以免打断看盘。更新前仍建议先退出程序并备份 `%APPDATA%\quant-desktop\`。

### 1.3 启动、隐藏与退出

- 启动后会显示主窗口，并按上次状态显示或隐藏悬浮行情条。
- 点击主窗口右上角关闭按钮只会把主窗口隐藏到系统托盘，程序、行情轮询和已启用的提醒仍可能继续运行。
- 左键单击托盘图标：显示或隐藏主窗口。
- 右键托盘图标：可显示主界面、显示/隐藏行情条、检查更新（仅标准安装版）或退出。
- 需要彻底结束程序时，请使用托盘菜单“退出”。

## 2. 主界面

主界面从上到下包括顶栏、指数栏、自选股区域和状态栏。

### 2.1 顶栏与数据源

顶栏右侧显示当前行情数据源：

- **腾讯证券**：默认数据源；
- **新浪财经**：备用数据源。

点击数据源名称可切换，切换后程序会请求一次新数据。两个数据源都来自公开网络接口，字段完整度、更新时间和可用性可能不同；切换成功不等于数据源此刻一定有有效返回。

齿轮按钮打开“偏好设置”。

### 2.2 指数栏

指数栏展示程序当前支持的主要指数及其最新价、涨跌额和涨跌幅。单击指数卡片可展开指数详情，再次单击或点击详情右上角关闭按钮可收起。

指数详情显示最新价、涨跌额、涨跌幅、成交量、成交额以及图表。指数详情与个股详情不会同时展开。

### 2.3 自选股表格

表格包含：代码、名称、最新价、涨跌幅、成本价、持股数、持仓市值、浮动盈亏、盈亏比例、涨跌额、成交量、成交额、换手率。

- 单击股票行：展开或收起详情。
- 双击股票行：打开该股票的行情提醒设置。
- 选中行后按 `Enter` 或 `A`：打开行情提醒设置。
- 选中行后按空格：展开或收起详情。
- 点击带排序能力的列标题：按该列排序；排序只改变当前表格视图，不改写保存的手工顺序。
- 右键股票行：设置提醒、置顶、上移、下移或删除/移出。
- A 股颜色采用红涨绿跌；涨跌为零时，部分位置按非负值样式显示。

表格较宽，窗口不足时可横向滚动查看右侧列。

### 2.4 添加自选

1. 点击“添加自选”。
2. 输入股票代码、部分代码、中文名称或拼音缩写。
3. 在搜索结果中点击股票或“添加自选”。

搜索最多返回 20 条匹配结果，并筛选程序可识别的 A 股、ETF、LOF 等标的。搜索依赖网络与公开接口；当前数据源无结果时程序会尝试另一数据源。当前版本不提供自选股文件导入/导出。

- 在“全部”中添加：加入全局自选。
- 在自定义组中添加：先加入全局自选，同时加入当前组。
- 同一市场、同一代码不会在“全部”中重复创建。

### 2.5 行情缓存

程序会把成功取得的行情写入本地缓存，重启后可先显示最近一次缓存。缓存数据可能不是当前行情；当行情连接异常、休市或请求时段外时，界面上的旧值不应视为实时数据。

## 3. 分组

### 3.1 “全部”的含义

“全部”是固定的全局自选集合：

- 永久存在，不能改名或删除；
- 包含所有已加入的自选股票，并按股票去重；
- 自定义组只是对“全部”中股票的引用，不会复制出独立持仓或独立提醒；
- 一只股票可以同时属于多个自定义组。

程序会保存当前组，主窗口与悬浮窗同步使用同一个当前组。

### 3.2 创建、改名和加入股票

- 点击“＋ 新建分组”创建组。
- 名称为 1–30 个字符，不能是“全部”，且不能与已有组重名。
- 进入自定义组后，可点击“改名”。
- 可通过“从全部自选加入当前组”把已有股票加入当前组。
- 也可停留在自定义组，直接点击“添加自选”搜索；成功后股票会同时进入“全部”和当前组。

### 3.3 排序

在当前组中右键股票，可选择“置顶”“上移”“下移”。

- 在“全部”中操作，修改全局自选顺序。
- 在自定义组中操作，只修改该组自己的顺序。

### 3.4 移出、删除股票与删除组

这三种操作含义不同：

| 操作位置 | 菜单/按钮 | 实际结果 |
|---|---|---|
| 自定义组中的股票 | 从当前分组移出 | 只删除该组关系；股票仍留在“全部”，其他组、持仓和提醒均保留 |
| “全部”中的股票 | 从全部自选删除 | 弹出确认；删除股票，并清理其所有分组关系、持仓和逐票提醒，无法撤销 |
| 自定义组工具栏 | 删除组 | 只删除该组及组内关系；股票、持仓和提醒仍保留在“全部” |

删除当前自定义组后会回到“全部”。

### 3.5 当前组对行情和提醒的影响

程序只主动获取、展示和监控**当前组**中的自选股票：

- 切到自定义组后，其他组中但不在当前组的股票暂停主动行情请求和提醒判断；
- “全部”被选中时，所有全局自选都属于当前监控范围；
- 切组后的第一笔有效报价主要用于建立价格观察基线，固定价格提醒不会因为刚切组就仅凭单点价格触发；
- 分组快捷键按“全部 → 各自定义组”的显示顺序循环，上一组/下一组均会首尾环绕。

## 4. 持仓与盈亏

### 4.1 设置持仓

点击表格“成本价”列中的“设置持仓”或已有成本价，填写：

- **每股成本价**：非负数字，最多 4 位小数；可留空；
- **持仓股数**：0 到 `9,000,000,000,000,000` 之间的整数，单位为股，不强制为 100 股的整手。

“清除持仓”会删除整条持仓记录。仅把成本价清空不会清空股数。持仓按股票保存，跨分组共享。

### 4.2 计算方式

使用最新可用行情价计算，结果显示到小数点后两位：

```text
持仓市值 = 最新价 × 持股数
成本总额 = 每股成本价 × 持股数
浮动盈亏 =（最新价 − 每股成本价）× 持股数
盈亏比例 = 浮动盈亏 ÷ 成本总额 × 100%
```

特殊情况：

- 未填写成本价：仍可计算持仓市值，浮动盈亏和盈亏比例显示 `--`。
- 成本价填写为 `0`：可计算浮动盈亏，但成本总额为零，盈亏比例没有数学意义，显示 `--`。
- 股数为 `0`：市值和盈亏为零；若成本总额为零，盈亏比例显示 `--`。
- 没有有效行情或行情价不大于零：相关计算显示 `--`。

### 4.3 计算局限

当前持仓是简化的手工记录，不是券商账户：

- 不计算佣金、印花税、过户费等交易费用；
- 不处理分红、送转、复权对成本的自动调整；
- 不记录逐笔买卖、已实现盈亏或资金流水；
- 不与券商同步，也不会验证实际持仓；
- 使用缓存行情时，市值和盈亏也只是基于缓存价格的估算。

## 5. 个股与指数图表

### 5.1 打开详情

单击自选股行打开个股详情。左侧显示行情摘要和五档盘口，右侧显示图表。盘口在详情打开时定时刷新；请求失败或请求时段外会显示相应提示。

单击指数卡片打开指数详情。个股详情和指数详情互斥，打开一个会关闭另一个。

### 5.2 图表周期

可选择：

- 分时；
- 日 K、周 K、月 K；
- “更多”中的 1 分、5 分、15 分、30 分、60 分 K 线。

新浪数据源不提供 1 分钟 K 线选项；若查看 1 分钟时切到新浪，界面会回落到 5 分钟。历史范围、时间连续性和最新一根 K 线是否更新，取决于数据源返回。

### 5.3 指标与操作

K 线（非“分时”）提供：

- 主图：均线（MA）或 BOLL；
- 副图：成交量（VOL）、MACD，以及“更多”中的 KDJ、RSI；
- 鼠标移动可查看对应 K 线数据；
- 图表缩放、拖动及向左查看历史数据由图表控件和数据源共同支持。

K 线按 A 股习惯显示红涨绿跌。图表和技术指标仅是数据展示工具，不提供交易信号保证。

## 6. 悬浮行情条

悬浮行情条是无边框、始终置顶、不占任务栏的 230 × 38 逻辑窗口。

- 显示当前组中的股票，每次最多显示 2 只；
- 股票超过 2 只时，每 3 秒向后轮播 2 只；
- 鼠标悬停时暂停轮播；
- 单击行情条显示主窗口；
- 按住并拖动可移动位置，程序会保存位置；
- 切换分组后会短暂显示当前组名；
- 可由托盘菜单或全局快捷键显示/隐藏。

如果保存的位置在当前显示器范围外，启动时会回到主显示器右下角附近。多显示器布局改变后，位置恢复以主显示器边界判断为主，可能需要重新拖动。

## 7. 行情提醒

### 7.1 打开逐票设置

以下任一方式可打开某只股票的提醒弹窗：

- 双击股票行；
- 右键股票行，选择“设置行情提醒”；
- 选中股票行后按 `Enter` 或 `A`。

每只股票可分别配置“涨跌幅提醒”和“固定价格提醒”。每类规则有两层状态：

1. 卡片顶部开关决定是否配置/删除这类规则；
2. “此规则启用”开关可暂停规则而保留阈值。

关闭卡片顶部开关并保存会删除对应规则；关闭“此规则启用”只会停用并保留规则。

### 7.2 涨跌幅提醒

涨跌幅使用数据源提供的**昨收价**计算：

```text
涨跌幅 =（当前价 − 昨收价）÷ 昨收价 × 100%
```

- 阈值 `5`：涨幅达到或超过 5% 时满足条件；
- 阈值 `-5`：跌幅达到或低于 -5% 时满足条件；
- 阈值可为正数或负数，但不能为 `0`，界面保留 2 位小数；
- 昨收无效、报价过旧或不是当天允许时段内的新报价时，不触发；
- 涨跌幅的观察值按北京时间日期重新建立，规则本身不会每日删除。

### 7.3 固定价格提醒

- 目标价格必须大于 `0`，界面保留 3 位小数；
- 规则长期保存，直至停用或删除；
- 从目标价下方到达/越过目标价，触发“向上穿越”；
- 从目标价上方到达/越过目标价，触发“向下穿越”；
- 行情直接跳过目标价也算穿越；
- 价格保持在目标价，或从恰好等于目标价继续向同侧移动，不会连续重复；
- 固定价格的观察基线可跨日期保存，因此隔夜或重启前后的两个有效观察值也可能构成穿越。

当前界面不让用户预先限定“只向上”或“只向下”；同一固定价格规则会识别两个方向。

### 7.4 三种重复方式

| 方式 | 涨跌幅规则 | 固定价格规则 |
|---|---|---|
| 每日一次 | 条件满足后当天最多一次，次日重新生效 | 仍须发生新穿越；同一天最多一次 |
| 重新穿越 | 先回到阈值另一侧，再次进入条件区才触发 | 每次从目标价另一侧重新穿越才触发 |
| 冷却间隔 | 条件持续成立时，每个冷却期最多一次 | 必须有新穿越，并且已超过冷却时间 |

冷却时间必须是 1–1440 分钟的整数，默认 30 分钟。

### 7.5 总开关与当前组

“设置 → 提醒 → 启用行情提醒”是总开关，默认开启。

- 关闭总开关只暂停通知，不删除逐票规则、阈值或启用状态；
- 暂停期间程序仍可能更新规则的价格观察状态，因此重新打开后不会补发暂停期间错过的穿越；
- 仅当前组股票会被主动获取和检查；其他组股票即使设置了规则，也不会额外请求行情；
- 从“全部”删除股票会连同其提醒一起删除；从自定义组移出或删除组不会删除提醒。

### 7.6 提醒有效时段与报价要求

真实行情提醒当前只在北京时间工作日以下半开区间内判断：

- `09:15:00`（含）至 `11:30:00`（不含）；
- `13:00:00`（含）至 `15:00:00`（不含）。

报价还必须为当天报价，时间不能晚于本机判断时间，且与当前时间相差不超过 5 分钟。恢复出来的缓存、请求失败后的缓存回退不会触发通知。

“设置 → 行情”中自定义的请求时段会决定程序是否取得新行情，但提醒判断仍受上述固定时段限制：把请求时段扩展到上述范围之外，并不会让提醒在扩展时段触发。

## 8. 通知与提醒记录

### 8.1 通知通道

真实提醒与“发送测试通知”使用同一发送路径：

1. 优先请求 Windows 原生通知；
2. 原生发送明确失败时，自动尝试独立桌面提醒窗兜底；
3. 若开启“同时显示桌面提醒”，即使 Windows 返回已受理，也同时排队显示桌面提醒。

Windows 接口返回“已受理”只说明系统接收了发送请求，**不代表屏幕上一定出现横幅**。Windows 勿扰、专注助手、应用通知权限、企业策略、通知中心状态等都可能隐藏横幅。测试通知成功也只验证发送路径，不代表后续行情一定满足规则，更不代表横幅必然可见。

桌面提醒是应用自己的置顶提示窗，用于系统通知不可见时兜底；它不修改 Windows 的通知、勿扰或企业策略。

### 8.2 Windows 通知身份

绿色版首次使用原生通知前：

1. 打开“设置 → 提醒”。
2. 点击“启用 Windows 通知”。
3. 再点击“发送测试通知”，检查界面返回的 Windows 与桌面通道状态。

该操作会在当前用户开始菜单中创建：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\QuantDesktop.lnk
```

该快捷方式指向当前 `quant-desktop.exe`，并声明应用通知身份 `com.chinesecanfly-wxy.quant-desktop`。它不是桌面快捷方式，不需要管理员权限，也不会修改系统通知策略。

重要限制与处理方法：

- 若同一路径已经有一个目标或身份不匹配的 `QuantDesktop.lnk`，程序为避免覆盖其他快捷方式会拒绝注册。
- 绿色版目录移动后，旧快捷方式仍可能指向原目录；当前“修复 Windows 通知身份”不会自动覆盖这个路径不匹配的 `.lnk`。
- 此时请先完全退出 QuantDesktop，手工删除上述 `QuantDesktop.lnk`，从新目录重新启动程序，再到“设置 → 提醒”点击“启用 Windows 通知”。
- 删除该 `.lnk` 只影响 Windows 原生通知身份和开始菜单入口，不会删除自选、持仓或提醒规则。

### 8.3 桌面提醒兜底

如果测试结果显示 Windows“已受理”但未看到横幅：

- 点击“没看到系统通知，启用桌面兜底”，或打开“同时显示桌面提醒”；
- 再发一次测试通知观察独立桌面提醒；
- 桌面兜底依赖应用仍在运行，不等同于 Windows 通知中心中的持久通知。

### 8.4 提醒记录与清空

本次运行产生提醒后，主窗口右下角会出现“提醒记录 · N”：

- 只保留本次运行最近 50 条；退出并重新启动后不保留这份界面历史；
- 记录显示标题、正文、时间以及系统/桌面通道状态；
- “清空记录”只清除本次运行的展示历史；
- 清空不会删除逐票规则，也不会重置冷却时间、每日触发标记或价格观察基线。

## 9. 偏好设置详解

设置保存后通常立即生效；出现“保存失败”时，不应把界面上的临时变化视为已经成功保存。

### 9.1 行情

#### 自动调节刷新间隔

- 默认：开启（保存值 `0`，表示自动）。
- 自动模式按市场阶段采用推荐节奏，例如交易中约 2 秒、盘前约 5 秒、午休约 10 秒、休市约 30 秒；连续行情无变化时还可能自动降到约 30 秒。
- 关闭后可设置固定间隔：**1–60 秒**，整数。
- 固定模式只固定轮询间隔，**不会绕过行情获取时间、周末或额外休市日期限制**。
- 实际更新还受网络耗时、数据源响应、行情是否变化和系统调度影响，设置值不是刷新时刻保证。

#### 行情获取时间

- 默认北京时间工作日：`09:15–11:30`、`13:00–15:00`。
- 至少保留 1 个时段，最多可在界面中添加到 8 个。
- 保存时会按开始时间排序；每段开始必须早于结束，时段不能重叠。
- 起始时刻包含，结束时刻不包含；例如 `15:00` 起不再发起该时段的请求。
- 可填写“额外休市日期”，格式为 `YYYY-MM-DD`，一行一个；空格、英文逗号或中文逗号分隔也可识别。
- 当前仅内置周六、周日判断，没有完整交易所节假日日历，也不会联网探测休市日；法定节假日、临时休市需自行填写。
- 非允许时间内，股票、指数、搜索、盘口和图表等网络行情请求会暂停；已有缓存仍可显示，详情没有缓存时会提示暂停原因。
- 自定义时段只控制行情请求范围；真实提醒仍只在“7.6”列出的固定时段判断。

### 9.2 提醒

| 设置 | 默认 | 实际作用 |
|---|---:|---|
| 启用行情提醒 | 开 | 总开关；关闭只暂停通知，不删除逐票规则 |
| Windows 通知身份 | 未必已注册 | 当前用户主动创建/核对开始菜单 `.lnk` 与 AUMID |
| 同时显示桌面提醒 | 关 | Windows 已受理时也显示应用桌面提醒；原生明确失败时即使关闭也会尝试兜底 |
| 发送测试通知 | — | 测试当前通知发送路径；不测试行情阈值是否会触发，也不保证横幅可见 |

逐票阈值、重复方式和冷却范围见第 7 章。

### 9.3 悬浮窗

#### 切换分组快捷键

- “上一分组”“下一分组”真实默认均为**空**，即未注册、未启用。
- 输入如 `Ctrl+Alt+Left` 后分别点击“保存”。
- 留空并保存可停用对应方向。
- 快捷键全局生效，并同步切换主窗口和悬浮窗使用的当前组。
- 组合键必须能被系统快捷键解析且未被其他程序占用；保存失败时旧快捷键会尽量保留。
- 输入框是文本输入，不会替用户检查所有操作系统级冲突，建议保存后在其他应用界面实际按键验证。

#### 显示/隐藏悬浮窗快捷键

- 默认：`Alt+Q`。
- 点击“录制”或快捷键框，按下至少包含一个修饰键（`Ctrl`、`Alt`、`Shift` 或 `Super`）的组合；`Enter` 确认，`Esc` 取消。
- 支持字母/数字、方向键、空格和功能键等可解析主键。
- “重置”恢复为 `Alt+Q`。
- 当前界面没有把此快捷键留空停用的操作；若新组合键无效或被占用，保存会失败，旧键保留。

#### 透明度与颜色

| 设置 | 默认 | 范围/作用 |
|---|---:|---|
| 透明度 | 100% | 5%–100%，控制整个悬浮窗原生窗口透明度；越低越难看清 |
| 单色显示 | 关 | 关闭红涨绿跌，将名称、价格、涨跌幅等统一为指定颜色 |
| 字体颜色 | `#9AA5B1` | 仅在单色显示开启时使用颜色选择器设置 |

透明度依赖 Windows 原生分层窗口能力；不同 Windows、显卡或远程桌面环境中的视觉效果可能不同。

### 9.4 外观

- 默认主题：浅色。
- 可选浅色或深色。
- 主题会同步到主窗口和悬浮窗，并保存供下次启动恢复。

### 9.5 系统

#### 开机自启

- 默认：关闭。
- 开启后，当前用户登录 Windows 时自动启动 QuantDesktop。
- 此功能依赖 Windows 当前用户的自启动注册能力和系统/企业策略；设置保存失败时请按界面错误处理，不要假定已启用。

#### 运行模式

只读显示“便携模式”或“标准安装”。运行模式由启动时 `quant-desktop.exe` 同级是否存在 `portable.dat` 决定，不能在设置界面直接切换。

#### 主窗口打开大小

- 默认：`1000 × 680` 逻辑像素；
- 宽度范围：**640–7680**；
- 高度范围：**480–4320**；
- 保存时立即应用；超出当前屏幕可用范围时会自动缩小。

“记住上次窗口大小”默认关闭：

- 关闭：每次从隐藏状态重新打开或下次启动时使用设置的固定大小；启动时居中。
- 开启：使用最近保存的窗口大小、位置和最大化状态；移动或缩放停止约 0.8 秒后保存。
- 显示器布局变化时，程序会校验边界；无效位置或尺寸会回退到可见范围，但多显示器复杂布局下仍可能需要手工调整。

## 10. 常见问题

### 10.1 双击绿色版没有界面

- 确认压缩包已完整解压；
- 安装或修复 Microsoft Edge WebView2 Runtime；
- 检查安全软件是否拦截程序；
- 查看同级 `data/quant-desktop.log` 是否有错误；
- 不要删除 `portable.dat` 来“修复”启动，否则程序会切换到标准数据目录，看起来像数据丢失。

### 10.2 关闭窗口后程序仍在运行

这是预期行为。关闭主窗口只隐藏到托盘。请右键托盘图标选择“退出”。

### 10.3 行情不更新或显示旧值

- 查看是否处于配置的行情获取时段；
- 检查当天是否被填写为额外休市日；
- 尝试在顶栏切换腾讯/新浪数据源；
- 检查网络代理、防火墙和公开数据源是否可访问；
- 缓存值可在休市或请求失败时继续显示，因此看到数字不代表它是实时值。

### 10.4 搜不到股票

搜索依赖在线接口，并按当前支持的 A 股、ETF、LOF 等类型过滤。可尝试输入完整 6 位代码、中文名称或拼音缩写，并切换数据源后重试。当前版本不支持港股、美股搜索与行情。

### 10.5 提醒规则满足但没有通知

依次检查：

1. 设置中的行情提醒总开关是否开启；
2. 该股票的对应规则是否“已配置”且“此规则启用”；
3. 股票是否位于当前组；
4. 当前是否在工作日 `09:15–11:30` 或 `13:00–15:00` 的提醒判断时段；
5. 是否取得了当天、5 分钟内的新鲜报价，而非缓存；
6. “每日一次”是否当天已经触发，或冷却时间是否尚未结束；
7. Windows 通知身份是否注册，勿扰/企业策略是否隐藏横幅；
8. 打开“同时显示桌面提醒”后再测试。

固定价格必须发生穿越；仅在设置规则时价格已经位于目标价某一侧，不会凭当前单点立即触发。

### 10.6 测试通知显示“Windows 已受理”，但没有横幅

“已受理”不是“已显示”。开启“同时显示桌面提醒”，并检查 Windows 通知、勿扰、专注助手与企业策略。测试结果也不代表真实行情规则已经触发。

### 10.7 移动绿色版后无法修复 Windows 通知身份

完全退出程序，删除：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\QuantDesktop.lnk
```

从新目录启动，再到“设置 → 提醒”点击“启用 Windows 通知”。当前版本不会自动覆盖目标路径不匹配的同名快捷方式。

### 10.8 盈亏比例显示 `--`

常见原因是成本价留空、成本总额为零、没有有效行情，或行情价无效。成本价为零时浮动盈亏仍可显示，但收益率无定义。

### 10.9 悬浮窗不见了

- 按默认 `Alt+Q`；若改过快捷键，使用新组合键；
- 右键托盘图标选择“显示/隐藏行情条”；
- 快捷键可能被其他程序占用，重新保存并测试；
- 显示器布局改变后，重启程序让位置校验生效；
- 透明度过低时，提高到 100% 排查。

### 10.10 绿色版升级后自选或设置为空

先退出程序，确认新 `quant-desktop.exe` 同级有 `portable.dat`，并确认旧版 `data/` 已完整复制到新目录。不要把标准模式的 `%APPDATA%\quant-desktop\` 与绿色版同级 `data/` 混淆。

## 11. 已知限制

- 当前面向 A 股及搜索接口返回的部分 ETF、LOF 等标的，不支持港股、美股行情。
- 行情、搜索、盘口和图表依赖第三方公开接口，可能延迟、缺字段、限流、变更或暂时不可用；腾讯与新浪结果可能不完全一致。
- 缓存用于快速恢复显示，不保证是当前交易时刻的数据。
- 当前仅内置周末判断，没有完整交易所节假日日历；休市日期需手工维护。
- 自定义行情请求时段不会扩展提醒判断时段；提醒固定在工作日 `09:15–11:30`、`13:00–15:00` 内。
- 提醒只监控当前组，不会后台同时监控所有组。
- Windows 通知“已受理”不保证横幅可见；桌面兜底也要求应用仍在运行。
- 绿色版移动后，通知 `.lnk` 可能失效，当前需手工删除旧快捷方式后重新启用。
- 提醒记录只保留本次运行最近 50 条，不是长期审计记录；清空记录不重置规则状态。
- 持仓和盈亏是手工、简化估算，不包含费用、分红、复权、已实现盈亏或券商同步。
- 新浪数据源不提供 1 分钟 K 线；不同周期的历史长度由数据源决定。
- 主窗口和悬浮窗的位置恢复主要按主显示器边界校验，复杂多屏或远程桌面切换后可能需要重新调整。
- 绿色版不提供应用内更新，需要手工下载、备份并替换版本。
- 当前版本不提供自选股 JSON/CSV 导入导出。
- 原生通知、全局快捷键、透明度、开机自启等能力受 Windows 版本、当前用户权限、企业策略及其他软件冲突影响；界面保存成功不应被解读为所有电脑环境都已实机验证通过。
