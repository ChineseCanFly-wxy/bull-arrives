# 全自动模型模拟交易（2026-10-04）

模型跟随账户现在由程序自动观察、提交委托、用新盘口模拟撮合并记录现金与持仓。你开启通知后接收买卖成交结果，不需要逐笔确认。通知开关和账户交易开关独立。

## 怎么使用

在研究中心的“跟随原模型 · 模拟交易”区域，选择已有五个冻结模型中合格的 forward / baseline / 20日来源，设置模拟本金和最多持股数，点击开启跟随。已有账户自动迁移：保留真实模拟成交形成的现金、持仓和历史；撤销旧未成交人工计划，再按当前有效模型条件生成自动委托。

每个模型使用独立账户、持股上限、仓位政策和时点政策，不共享其他模型的评分。当前独立默认上限为2 / 3 / 3 / 5 / 2只，允许每个账户设置1—10只。原预测模型、训练文件和模型阈值沿用已有冻结结果；研究通过的仓位与条件入场规则继续有效。

- **开启跟随**：程序自动执行，不出现“确认买入 / 确认卖出”按钮。
- **开启通知**：实际模拟成交后发送股票、方向、股数、成交价格、成交时间及原因，并标记账户与订单。
- **关闭通知**：不弹出买卖通知，账户继续自动买卖；成交和通知历史仍可核对。
- **暂停跟随**：撤销未成交单并停止该账户撮合，保留已成交持仓与现金；恢复后按当前条件执行。
- **撤销委托**：可干预未成交单，不改变已经发生的成交。仍开启的账户随后可以依照有效条件生成新的卖出委托。

保持应用运行、行情可用和研究日线数据及时更新。关闭程序期间没有后台执行；重启会恢复持久化账户状态，但不补成交已经错过的买入窗口。

## 盘中什么时候会操作

时间均为北京时间，按应用载入且已核验的A股交易日历执行。

| 操作 | 当前执行窗口 | 条件 |
|---|---|---|
| 自动买入 | 信号完成日的下一交易日09:30—09:35 | 原模型资格和已通过的条件成立，有现金与名额，通过高开约束，随后新卖盘可成交 |
| 自动卖出 | 交易日09:30—11:30、13:00—14:57 | 完成日退出条件成立，符合T+1，有可卖股数，随后新买盘可成交 |
| 午休、非交易日、窗口外 | 不成交 | 等待下次合格条件；过期单结束，买入不追单 |

这五个模型按完成日数据判断资格和退出。盘中负责自动执行与撮合，不会因为盘中某次价格下跌就把原收盘3ATR规则改成即时止损。当前没有采用未经研究的新盘中止损、午后补买或新提前退出规则。

卖出限价不再满足后来有效的买一价时，程序会撤销旧单，用当前可见买一及原滑点重新计算卖出限价、自动提交，再等待这次提交之后的新盘口。买入保留当日开盘与原滑点限价，错过不追高。

## 什么才算成交

自动提交产生“程序已提交 · 待撮合”记录，不立即扣款、不增加持仓、也不发送买卖成交通知。未成交买单会预留现金和名额，避免并发超买。

成交必须同时满足：报价与盘口新于提交时间，价格和对手盘深度可成交，订单未过期，处于有效交易时段，股票状态合格，现金与费用充足，股数与整手要求正确，卖出符合T+1；源模型、研究日期和执行政策指纹仍有效。成交后原子更新现金、费用和持仓，重复轮询不重复成交，成交提醒不在重启后重复发送。

停牌、缺对手盘、数据过期和公司行动权益待核对时保留记录并等待或结束该委托，不生成假成交。持有期是计划上限；遇到不能成交的情况，实际持有可能超期。账户页面展示实际成交和净值，不将多年回测曲线冒充这个新模拟账户的收益。
