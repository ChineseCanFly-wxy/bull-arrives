# 市场主线与自动账户优化 · 2026-10-05

## 日常使用

1. 在顶部“模拟账户”保存“新自动模型账户初始资金”，默认每个账户10万元。修改预设只影响后续创建的账户；已有账户的金额和持股上限在各自账户中调整。
2. 启用本地历史数据，选好 StockDB 与数据更新程序，保持应用运行。A股交易日默认09:00更新；超过时间启动且当天尚未执行时会补做一次。当天执行记录保存在数据库，失败或中断后不自动重试，重启不会重复执行。更新会暂停已经确认的本地服务，更新并核验完成后恢复原服务。
3. 更新成功10分钟后，研究中心自动检查现有5个冻结模型。只有同时满足模型入场条件和资金整手要求，才创建对应模型的独立模拟账户；已有账户更新计划、保留资金与持仓。程序在原模型的有效时段自动提交委托，等待合格新盘口撮合。无需每天筛选、选择来源、绑定账户或逐笔确认。
4. 研究中心用账户卡片查看和切换净值、现金、持仓、委托。需要调整金额或持股数量时，打开对应模拟账户；关闭后返回研究中心。开启研究提醒后通知实际模拟成交。手动条件提醒与市场主线观察独立使用。

顶部“更新数据”和深入研究中的“更新历史数据”均保留。手动更新不受自动更新开关或非交易日限制，也不要求先退出 StockDB 服务。

## 防止自动流程重复操作

- 同一模型复用一个独立账户。创建账户在数据库写事务中再次检查模型和用户状态，两实例同时运行也不能据旧快照重复创建。
- 当日任务记录已完成的模型、来源日期与内容指纹；下一次定时检查或重启应用只核验记录。来源改变时仅刷新对应模型，不再创建第二账户。没有候选是本轮有效结果，不反复研究同一来源。
- 部分失败只重试尚未完成的模型，5分钟间隔、同一轮最多5次；成功模型与旧账户继续保留。StockDB 数据更新每天只自动执行一次，失败后保留原因，可手动更新或等待下一交易日。
- 全局暂停会停止自动发现和自动买卖、撤销未成交委托，保留账户与持仓。单模型暂停或删除会持久保存用户决定，恢复全局自动运行不会自动复活该模型。
- 用户操作优先于后台旧结果；新建、刷新上下文及撮合前再核对状态。不同账户的账本独立，模拟撮合在同一数据库事务中读取现金与剩余盘口，防止并发重复使用同一份成交量。

## 市场主线

顶部“市场主线”点击“开始全市场扫描”一次。关闭页面仍在后台运行，显式暂停会取消正在处理的任务；继续从最近保存进度恢复。当天完整扫描完成后等待新的完成交易日，不反复扫描同一日。失败板块可主动继续重试。

修复了备用板块源混入非交易日造成的日期错配：只剔除交易日历证据确认休市的多余行；真实交易日缺行仍保留失败原因。近期60日窗口与沪深300使用相同真实交易日，不能靠截取共同日期隐藏缺数据。

有少数成分缺失时，详情仍显示通过日期、趋势与风险检查的个股候选，并明确标记“覆盖未全”。个股默认展示10只，可选择3、5或10只并记住选择；展示数量不影响观察条件或通知中的前3只候选。板块很强但距离均线超过2ATR时仍保留强度排名，显示等待回落状态；完整覆盖未通过时不称全市场最强，不发送已通过完整核验的主线提醒。

新增31个行业的历史研究没有证明换掉原20/60日默认更稳，因此保留原规则。行业指数研究与现有个股冻结模型分别留存；详情见 [主线研究结果](../research/ashare-mainline-2026-10-05/RESULTS.md)。
