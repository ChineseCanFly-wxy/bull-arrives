# 研究中心：从想法到前向证据

## 实时、日线与并行对照（最新）

在“验证配置 → 模拟执行方式”选择，保存后对新候选生效：

| 模式 | 成交依据 | 用途 |
|---|---|---|
| 实时前向（默认） | 委托建立之后收到的新鲜报价与对手盘口 | 验证未来盘中触价、限价、价差、滑点与 T+1 |
| 日线前向 | 已完成日线信号，之后交易日开盘价 | 对照日线策略，保留原实现 |
| 并行对照 | 同一候选创建两个独立账户，各按自己的口径执行 | 观察两种执行方式的实际差异，主考核依据实时账户 |

两边的资金、订单、净值、回撤与样本独立，不合并胜率，也不选择较好的那边冒充整体成绩。两种执行方式连同触发逻辑都可能不同，结果差额不能全部归因于滑点。日线前向也可以等待未来日线，并不等于历史回测；历史回测仍作为单独的研究工具。

**实时口径**：买入参考卖一、卖出参考买一，滑点后的价格不能突破限价；最优档可见数量不足则整笔等待，本版不虚构排队成交或部分成交。委托建立当时的旧报价不能成交，同一盘口时点不重复使用挂单量。当天未成交限价委托过期，不用次日开盘或当天高低点事后补成交。

**34 买、35 卖示例**：新建实时模拟账户，在手动指令填写买入限价 34、止盈 35、低于买入价的止损与数量。新鲜卖一及滑点满足买价才模拟买入；当日到 35 受 A 股 T+1 限制不能卖，后续交易日有可卖持仓且新鲜买一满足限价才模拟卖出。若设滑点，卖一正好 34 时滑点后超出 34 限价会继续等待，不偷改你的限价。

**只交易 A 股**：代码限定沪深北股票，拒绝港美股、基金、债券和指数。自动研究选股仍限沪深主板。全部时钟以北京时间计算；**交易日历由上证指数行情自己推断** —— 指数日 K 有这一天就是交易日，盘中再用一次实时报价确认今天是否开市，节假日因此会自动识别，跨年也不需要更新代码或手工录入休市日。只有行情通道全部不可用时才回退到公告日历（见 [上交所休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20251222_10802510.shtml)、[深交所休市安排](https://investor.szse.cn/disclosure/notice/general/t20251222_618087.html)），两者都拿不到证据时按休市暂停，不会猜一个交易日去撮合。设置页「自动调节刷新间隔」下方会显示当前日历覆盖区间与来源。

**交易规则按板块自动判定**：涨跌幅主板 ±10%（主板 ST / *ST 自 2026-07-06 起由 5% 放宽至 10%，与普通股票并轨）、创业板与科创板 ±20%、北交所 ±30%（注册制板块的 ST 不改变比例）；买入申报单位科创板 200 股起、北交所 100 股起（超出部分 1 股递增），沪深主板与创业板为 100 股整手；卖出允许零股，但一手以内的余额必须一次性卖出。以涨停/跌停价开盘但**盘中开板**（当日有振幅）的仍按开板价撮合，只有全天封死的一字板才拒单。退市整理期与上市未满 5 个交易日（简称带 `N` / `C`）的股票没有可套用的涨跌幅比例，不参与模拟。这些判断不读账户里的配置，配错参数也不会改变撮合结果，旧账户会自动按规则重算。

**交易时段**：实时模拟只处理 09:30–11:30、13:00–14:57 连续竞价；午休、集合竞价、休市不模拟成交。除权跨日参考价异常需要人工复核，当前不宣称完整复现交易所撮合。

**使用要求**：实时账户保持程序运行与网络可用，上一轮完成后约 3 秒再检查；请求多只股票可能增加延迟，不保证每个 tick 都收到。不会补做断线期间的交易。日 K 仅用于提前形成趋势/买卖区间，不用于伪造实时成交。账户可查看买卖区间、等待原因及最近成交时的报价证据。

**收益与回撤**：实时按观测到的盘中净值维护高水位及最大回撤，并保留分钟内净值高低；图表仍是日终概览，不能把断线时段或未观测低点当成完整风险。日线对照继续使用日级回撤。同期基准要求首次与当前估值时点均可用，不能拿较短区间替代。

## 这版已经连通的流程

AI 提出候选（或 Claude 交互研究后导入）→ 登记现有策略版本库 → 自动筛选沪深主板股票 → 冻结股票池与执行规则 → 创建独立模拟账户 → 自动按新日线推进 → 收益/回撤/基准/样本联合考核 → 人工保留为研究策略或淘汰 → 保留的继续跟踪。

本次只修改源码和测试，没有构建或替换 exe。运行旧的根目录程序不会出现这些新入口。

这是一条**研究实验闭环**。它使用三种已有执行规则，不能解释成“任意新算法自动完成全部历史实战门禁”。原有策略库的历史组合、公司行为、实盘准入门禁没有被绕过；研究中心中的“采纳”表示继续保留为研究策略，不会下真实订单，也不承诺盈利。

## 第一次使用

1. 在设置 → 行情启用本地历史引擎，更新数据。模拟需要前复权与未复权日 K，选中的每只股票至少 60 根。只有应用里的在线报价不够。
2. 在设置 → 智能中检测 Claude Code，并测试连接。自动分析使用 Claude 已有模型和认证，不需要在应用填写密钥。
3. 点击顶栏文字按钮 **研究中心**，打开 **验证配置**。
4. 初次可以保留默认：每实验资金 10 万元、观察 28 天、至少 20 笔已完成卖出、回撤上限 15%、收益大于零且超过同期沪深 300、5 只股票、最多 3 个候选/运行实验。默认只是研究起点，不是对你适合的投资阈值或盈利保证。
5. 根据自己的模拟口径核对佣金、最低佣金、税费与滑点，点击保存。新候选会冻结这些配置，修改默认配置不会改变旧实验。
6. 第一条实验建议手动启动。跑通并理解数据更新要求后，再开启盘后自动研究。

## 路线 A：应用自动提出候选

1. 在 **策略实验** 点击 **AI 研究新候选**。
2. 应用把市场汇总、过去实验的状态和真实前向指标交给 Claude。Claude 从趋势回踩、均值回归、放量突破三种规则中选一种，提出筛选参数、适用假设和失效解释。
3. 返回内容必须通过严格字段、规则和数值校验；重复规则与参数不重复登记。
4. 阅读候选卡。选择 **自动选股并启动验证**。
5. 程序按冻结的价格、换手率和成交额条件筛选沪深主板，强制排除 ST、退市、停牌与一字板。命中后按成交额排序取配置数量。股票池和选股快照一并保存；缺字段、陈旧快照、历史数据不足时保留候选并说明原因。
6. 自动创建隔离的模拟账户，沿用现有确定性执行规则。不是让 AI 临时指定买卖价，也不是让 Claude 直接写数据库。

当前这一代实验只做**一次冻结选股**，不会每天用新股票替换原股票池。这样先测清楚一份候选的前向表现。每日动态轮动、更多执行规则和任意程序化策略仍需后续扩展。

## 路线 B：打开真实 Claude Code，使用你的 Skill

1. 打开 **Claude 交互研究** → **查看研究任务书与个人 Skill**。
2. 点击 **打开 Claude 研究窗口**。Windows 通过 Windows Terminal 创建真实交互终端；不使用 `-p`，不传 `--safe-mode`，保留 Claude 的个人 Skill/插件发现。权限模式为 `default`，具体工具权限由 Claude 提示或其有效配置处理。
3. 这是用户主动管理的会话。应用不会把它宣传成隔离沙箱，关闭研究中心也不会结束它。没有 Windows Terminal 时会给出专用目录，手动进入该目录运行 `claude`。
4. 初始消息要求 Claude 阅读目录中的 `BULL_RESEARCH.md`。你可以直接说：

   > 使用我已安装的股票研究 Skill，研究一个可被证伪的主板策略假设。先列明你实际取得的数据、来源、日期和缺失信息，再解释支持因素与反证。不要根据历史最高收益挑参数。仅使用任务书支持的执行规则，完成后输出 candidate.json，并说明适用环境和失败条件。

5. Claude 将候选保存为专用目录下的 `candidate.json`。应用只接受不超过 16 KiB 的普通 JSON 文件，并严格验证字段，不执行候选中的代码。
6. 回到研究中心点击 **导入 candidate.json**。导入是新增版本登记，不覆盖现有策略；随后按路线 A 启动验证。

界面列出的 Skill 名称来自 `~/.claude/skills`，只是发现列表，**不等于该次会话实际调用记录**。插件 Skill 和实际使用情况应在 Claude 交互窗口确认。应用没有安装未知第三方 Skill，也没有改写你的全局配置。

## 每天怎样让模拟继续

- 保持应用运行（隐藏到托盘可以，彻底退出不可以）。
- 盘后更新本地历史数据，再看研究中心的 **立即推进** 或等待后台检查。
- 实时模式在上述 A 股连续竞价时段监听未来新鲜报价；有信号才生成指令，新盘口满足成交条件才记账。
- 日线模式仍约每 5 分钟检查账户、交易日 16:00 后推进；等待之后交易日未复权数据，按次日开盘假设处理信号。并行模式同时保留两种账本。
- 止损、止盈、最长持有期由代码生成卖出条件，自动执行仍受 T+1、资金、涨跌停和数据检查限制。
- **暂停**停止后续指令和撮合，不自动清仓；待成交指令、持仓、账本保留。**恢复**继续原实验，不能更改规则重算旧绩效。
- 模拟账户的普通编辑、删除、手动加单入口不能修改研究中心绑定的冻结账户。需要不同条件时建立新候选。

数据缺口处理：实时账户遇到过期报价、盘口时间不一致或跨日参考异常时停止该轮执行并说明原因，不回填成交；日线对照遇到估值日期不同、多日缺口、公司行为等会阻止继续并报告原因。长时间关闭应用会影响两种前向实验的完整性。

## 开启无人值守研究

验证配置中的 **启用盘后自动研究与启动验证** 默认关闭。

开启后，在应用运行、AI 总开关允许的情况下，每个配置认定的交易日 16:00–22:00 最多进行一次：

1. 优先处理尚未启动的候选；没有候选且未达到数量上限时，让 AI 提出一个新的。
2. 校验、选股、检查本地历史、创建模拟账户并启动前向验证。
3. 失败当天不自动反复重试，原因显示在研究中心，可以手动处理。

关闭自动研究只停止新研究/启动，**不会停止已在运行的模拟实验**；已有实验要单独点暂停。暂停和淘汰记录均保留，最多 100 条实验记录，达到上限后停止新增。

程序不自动运行外部数据更新器，仍需要已有的本地历史更新流程。没有新数据时不会凭空产生净值或让考核时间成熟。

## 怎样看收益、回撤与考核

- 账户权益 = 现金 + 持仓按未复权收盘价估值。累计收益包含浮动盈亏及账本中扣除的费用。
- 最大回撤从**初始资金**开始计算高水位；例如最高 12 万元后跌到 10.8 万元，是 10% 回撤。
- 实时账户是已观测盘中净值回撤，日线账户是日级回撤，两者都不代表未观测时段的最坏情况。
- 样本量为完成卖出的订单数，不等于相互独立的交易机会，不能仅凭样本达标证明统计显著。
- 考核同时要求：观察时间到期、样本达标、足够净值记录、同期基准可用、累计收益超过冻结门槛并跑赢基准、回撤不超过上限。
- 未到期：验证中。时间到但样本/记录/基准不足：延长。回撤超限：停止该实验。到期收益不合格：淘汰。
- 达到门槛：待采纳，暂停自动成交以供检查。点击 **采纳为研究策略并继续跟踪** 后继续模拟；后续不达标仍会淘汰。
- 所有通过/失败都保留，后续 AI 研究会得到近期实验的实际指标，帮助提出下一份可测试假设。

建议先比较“原策略假设是否成立”，再看收益。不要用一次盈利反向解释所有理由，也不要为通过考核临时降低门槛。

## 资讯在哪里

主界面右下角始终显示 **资讯与提醒**：

- **公司资讯**：规则命中的相关资讯，展示来源、接收时间、AI 摘要/规则原文、采集到的原始标题与正文。
- **盘前 / 盘后**：目前仍是规则统计卡片，不能说成完整 AI 日报。
- **本次提醒**：原本的最近 50 条内存提醒，清空不影响新闻归档。

可以在此直接开启/暂停资讯采集，或在设置 → 提醒开启。资讯与时序卡片归档最近 500 条，重启可查。首次开启只建立水位，不补推旧新闻；周末、休市、没有命中规则时可能为空，这是正常状态。原文是数据源实际提供的内容，正文可能仅为摘要或未提供。

## 本轮验证与尚未验证的部分

已验证：真实 Claude 提出候选并登记、重复与越界拒绝、强制排除；合成数据模拟买卖到考核结论、采纳继续和淘汰停用；初始损失回撤、冻结账户、持久化资讯上限；前端类型与深浅色/窄窗口浏览器交互。

最新验证数字：默认 Rust 测试 220 通过、0 失败、19 项需要外部条件的手动测试默认忽略；另单独通过真实 Claude 策略候选测试和真实行情接口时间戳读取测试。实时测试覆盖 34 买/35 卖、T+1、旧报价、限价与滑点、缺少挂单量、休市、非 A 股拒绝、成交证据，以及并行账户独立和一起暂停。今天休市，没有进行盘中真实行情撮合验收。浏览器样例测试覆盖并行对照页面、配置/指引切换、暂停/恢复、深浅色与 760 像素窗口，无页面脚本异常及横向溢出。截图收益、标的和日期均为测试样例。

合成数据测试不证明任何策略盈利。没有替你开启真实账号的自动研究，没有创建你的正式实验账户。真实股票的多周考核需要在后续运行中完成；Windows Terminal 的交互窗口入口未在本轮替你实际打开。全市场接口与 stockdb 服务仍依赖本机数据和网络可用性。
