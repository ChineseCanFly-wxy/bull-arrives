# 研究提醒、模拟跟踪与提示修复（2026-10-04）

研究中心默认分为“自动模型交易”和“手动条件提醒”。自动交易按已启用的原模型使用专用账户；手动观察只提醒，不买卖、不需要资金账户。研究中心内容顶部只有一处“暂停提醒／恢复提醒”，在自动与手动页面通用，无需跳转设置；“通知测试与帮助”放在可选折叠区。研究提醒统一控制自动成交、手动条件和主线研究消息，独立于自选股行情提醒。暂停提醒只静音，不暂停模型计算和自动交易，记录仍保留。

## 使用已研究模型自动买卖

1. 打开“研究中心”。简化版默认进入“自动模型交易”。
2. 在“启用已验证模型”选择原模型、填写初始资金，默认10万元。每个模型自动使用已研究的数量与策略默认值：2/3/3/5/2只；“调整推荐数量”可改为1–10只。
3. 点击“按推荐一键启动自动模拟”。程序自动准备／更新合格模型来源并创建空仓交易账户，无需自行理解或选择来源。已有同模型账户则复用最近创建的账户，保留原资金、持仓与配置；暂停时会恢复跟随，不会反复新建账户。
4. 保持应用运行即可。无需每天筛选、逐只加入观察、确认成交或手动刷新。想接收实际模拟买卖消息时，保持“提醒”开启。通知包含账户、股票、买卖方向、股数、实际模拟成交价及北京时间；出现信号或提交委托不算成交。
5. 下方选择专用账户，查看持仓、成交与净收益。提醒只由研究中心顶部的统一开关管理；每个账户提供“暂停自动买卖／恢复自动买卖”和“删除模型”。暂停自动买卖后程序撤销未成交委托，保留持仓和历史成交。删除前展示账户编号、持仓、未成交与已成交数量；确认后停止并清除此模型专属模拟账户的持仓、委托、成交与资金调整记录。其他模型账户和原研究结果保留；再次启用从新空仓账户开始。

首次准备需要历史数据与现有模型程序，可能耗时；请保持应用运行。关闭研究页面不会取消后端准备，完成后账户保存在应用中；重新进入会自动读取。应用退出后不继续准备或交易，未完成时可再次点击启动；已保存来源与已有账户会复用。准备失败会显示原因，修正数据或配置后可重试，不伪造账户成交。

有账户后，“跟随其他模型（可选）”默认收起。其他模型出现候选不会自行新建交易账户，先启用该模型一次，之后其专用账户自行更新与买卖。“模型来源与另建自动账户（专业选项）”、原模型来源／历史对照、后台研究记录均默认折叠，日常无需操作。

来源账户提供冻结模型信号、排序、退出和研究身份。它必须是已登记模型的 forward / baseline / 20日来源，历史回放和 15日对照不会混入。这里的 20日是研究基准身份，不等于本人账户必须持满20天，各模型按自己的执行配置退出。

普通“模拟账户”存储资金、持仓与订单，不包含原模型来源信号，不能直接当作研究中心的来源。模型跟随账户在模拟账户页按“自动模型专用”分组，可以查看账本和调整资金。手动指令、观察及其他策略不能借用、改绑或手动撤销这个账户的订单；自动买卖控制位于研究中心。冻结研究对照账户保留原参数且只读。

## 每天自动选股与换股

自动交易使用所选模型的完整候选池，不要求把每只股票手动列入观察。创建跟随账户会开启原模型盘后自动更新；应用运行且历史数据齐备时，每个新的完成日会重新筛选、排序，账户同步新的模型计划。候选随日期变化，几天内可出现许多不同股票。

候选数量不等于同时持仓数量。程序根据原模型排序、入场条件、现金和空余名额买入，按模型退出条件卖出，不会仅为出现新候选就强行换掉尚未达到退出条件的持仓。上限限制的是同时持有数量，几天累计成交的股票可以更多。

五个来源使用完成日日线确定信号，买入在下一交易日有效窗口内执行；盘中检查委托撮合、T+1和可卖盘口等。应用关闭不会继续买卖，数据未齐备会等待，错过有效买入窗口不会补造旧价格成交。关闭研究提醒只静音，暂停跟随账户才暂停交易。

## 每日自动更新与失败重试

盘中实时报价、盘口和撮合继续使用行情数据源。盘后16:00起，将当天视为模型完成日；优先通过只读接口获取StockDB的完整日线。StockDB未更新、不可用或数据校验失败时，自动尝试新浪收盘行情，缺失股票再尝试腾讯。应用运行时，原模型更新失败会继续自动重试，不要求每天点刷新。

备用行情必须带目标日收盘时间，并通过真实沪深300、量额单位、昨收衔接和全市场覆盖检查；超过缺口、覆盖不足或未能核对复权时等待，不会把旧日数据当新信号。备用仅补与已保存快照相邻的一个完成交易日；若应用连续多个交易日未运行且StockDB尚未补齐，中间缺口需要历史数据。不能用当前实时报价编造这些旧日。

“模拟跟踪”顶部新增“模型行情数据”，自动显示应到日期、账户齐备数量；可展开核对采用StockDB还是备用行情，以及具体缺失原因。原模型参数、股票代码轴和历史前缀保持原样，已有现金、持仓与成交不会因换数据源重写。备用数据用过后，StockDB恢复时会核对跨源舍入差异再接回。

开启本地历史后，默认每天北京时间09:00后台运行现有StockDB更新程序。09:00后启动且当天未成功就补做；当天已成功，重开应用不重复更新。更新时间与自动更新开关在数据设置的可选详情调整。手动点击更新与定时更新使用同一流程：先核对本地服务的端口、进程和所选StockDB引擎，确认后自动停止服务；数据同步完成后恢复服务，再核对最新完成日。已由用户外部启动的同一引擎也能自动暂停并按原命令、工作目录及环境恢复，无需提前手动退出；更新失败同样尝试恢复。远程服务或身份不匹配的端口占用不会被结束，页面保留实际失败原因。新版支持同步与校验参数的更新程序分两步执行，旧版按原启动方式执行；两者均需核对最新完成日日线的日期、价格与市场覆盖，不能仅以进程退出算成功。

失败后从本次失败结束起，每隔1分钟再试；合计连续5次失败（首次加4次重试），当天停止自动重试并只弹一次“更新失败”。失败次数和提醒记录跨重启保留，次日重新尝试；修复问题后可手动点“更新数据”重试。此规则固定，不增加重试设置。这个更新失败提示独立于普通研究静音。

已移除缺行情的定时弹窗及其开关，数据状态和失败原因仍可展开查看，近期行情源兜底继续保留。自动更新不等于一定有合格数据，未齐备时仍由模型日期和执行守卫等待，不能放行旧数据交易。

行情未齐备时，模型跟随暂停生成和撮合依赖该数据的新买卖；保留已有持仓和账本。数据恢复后继续核对，错过09:30—09:35买入窗口不会追补成交。

## 手动观察与自动交易的分界

点击股票“观察”不会创建或占用模型交易账户，也不会下任何买卖委托；删除、修改该观察或统一暂停提醒，不会改变自动账户的候选池、仓位和退出规则。自动账户所需的原模型日线维护会继续运行，不能从手动观察关闭。

这五个冻结模型的已验证信号均来自完成日日线。点击候选股票“观察”时，默认选择原模型命中／失效，并同时开启原模型盘后自动更新。原模型的阈值、评分、排序不受影响。直接保存即可，当前命中静默登记，后续新确认或失效再提醒。

“调整观察条件”默认折叠，允许改为额外盘中确认、主线确认或自定义组合。手动修改按模型分别记住，重新打开同一股票的已有观察会优先读取其当前条件。额外盘中条件只用于观察，不改模型买卖策略，也不代表已完成其多年的收益验证。

手动提醒清单的每条记录都提供带图标的“删除”。点击后从清单和后台观察中移除，包括旧版已暂停的记录；已经产生的提醒证据仍可在提醒记录查看。删除失败保留原记录并显示原因。旧暂停记录保持暂停，可重新从该股筛选结果点击“观察”恢复；不再重复放逐条“暂停提醒／恢复提醒”按钮。

## 修改资金与普通模拟账户

研究中心在当前账户展开“调整资金、持股上限与模型规则（可选）”，可修改初始资金／累计投入；模拟账户页也提供资金调整。金额在1000元至1亿元之间，最多两位小数。程序按新旧金额差额增减可用现金，保留持仓、历史成交、费用和现有委托，并记录资金调整时间、金额与余额。减少投入不能使余额为负，也不能挤占未成交买单预留资金；失败不会部分修改。自动账户的资金基准同步更新，净收益按新累计投入显示，历史交易不重算，这不是重新回测模型。

普通手动账户与自动模型账户分别显示。手动交易请使用独立手动账户；研究对照账户只读，不能改资金。

## 普通手动账户的来源与模式

| 设置 | 作用 |
| --- | --- |
| 手动来源 | 接收“手动指令”提交的订单 |
| 现有规则来源 | 对填写的标的运行通用技术规则，不等同于五个冻结研究模型 |
| 仅记录 | 保存信号／计划，不成交 |
| 需确认 | 等用户确认后再撮合 |
| 全自动 | 合格信号由程序自行撮合；开启监听才持续检查，关闭时可立即运行 |

来源回答“接收谁的信号”，模式回答“收到后怎样处理”。按已研究模型全自动执行请使用研究中心的模型跟随流程。

## 市场主线怎么用

市场板块保留排行、轮动、成分股、K线与资金；重复的“主线发现”“主线研究”和跳转卡片已移除。顶部直接打开“市场主线” → 手动扫描候选 → 比较20日／60日相对沪深300强度 → 打开靠前板块核验成分和领涨观察。详情优先展示数据日期、领涨股票及5／20／60日表现；专业研究、公告来源和模型证据放在折叠区。观察及盘后提醒不使用交易账户、不改变原模型买卖。

“近期主线的历史提醒快照”读取最近14天已经留存的通知证据，打开的是当时快照；没有保存的日期不补造。可以比较同板块的留存相对强度差，但局部存档不能证明当时全市场最强。当前支持近期窗口比较和真实通知快照回看；尚没有任意历史起止日全市场排行、连续历史名次、牛熊阶段自动识别或使用历史时点成分的多年主线策略回测。主线发现使用当前成分，来源失败及日期不一致分别显示；不能把不完整扫描当成确定的最强。

## 分析里的“因子与形态历史统计”

这个入口用于辅助理解单只股票：三个因子（20日动量、5日反转、20日低波动）和三个形态（20日放量突破、10日超跌、趋势回踩），统计它们出现后5个交易日的价格变化。手动展开并点击“计算历史统计”才运行，不会创建模型、模拟账户或订单。

目前它将历史样本合并计算，未做滚动样本外检验，没有交易成本、可执行入场价、现金与组合账本。“历史上涨占比”是过去样本占比，不是本次预测概率；“信号后最低价最大跌幅”是信号日收盘到后续最低价的跌幅，不是账户回撤。历史特征一致性检查仅检查特征是否读取未来数据，不能当作盈利能力认证。

原页面“滚动检验”表述超过实现能力，本次已改为可选历史统计，默认折叠。这块可以作为研究线索；模型自动买卖仍以研究中心已冻结模型和本人的实际成交为准。

## 模拟费用

按本次要求，本人的跟随交易和普通模拟账户后续交易过户费为0、滑点为0，保留佣金与卖出印花税。已有普通／跟随账户启动后迁移执行参数；历史成交价、扣费、现金变动不重算。冻结研究对照和历史多年收益保留原成本口径，不能把它们直接当作现在账户的收益。

## 问号与账户选择修复

问号说明挂载到弹窗以外，并按实际尺寸在窗口内定位。内容变化、嵌套滚动和窗口缩放会重新定位；超长内容可在提示内滚动。键盘焦点、鼠标移入阅读和 Escape 关闭提示均保留。

模型来源加载／作业完成后自动选择可用来源。普通模拟账户在读取中切换账户会等待并读取最后选中的账户，旧请求不会覆盖新选择；下拉选项挂载到弹窗外避免裁切。
