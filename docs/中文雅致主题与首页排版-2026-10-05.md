# 中文雅致主题与首页排版 · 2026-10-05

打开顶部“设置 → 外观 → 界面风格”，选择“中文雅致”。明暗模式可独立选择，主题自动保存并在下次启动恢复；原版、清晰现代仍可随时切回。

## 新主题设计

- 常用中文字形：正文优先使用本机微软雅黑UI / 微软雅黑，其他系统使用苹方等本地字体；行情和资金数字使用Arial等常用无衬线字体，配合等宽数字对齐。不下载外部字体。
- 重新组织字号与密度：正文14px、辅助说明12—13px、明确的标题层级，指数行情30px，表格行高44px。导航、输入框和弹窗增加留白，减少编程终端式的数字视觉。
- 指数卡改为中性底色、左对齐名称和行情，涨红跌绿用数值和细色边提示，不铺满红绿背景；底部涨跌额与涨跌幅两端对齐。宽屏所有指数等宽铺满，窄屏在指数区域滚动。
- 表格、设置、研究中心、主线详情、模拟账户和悬浮窗继承同一套中文与数字字体。公共分时/K线图表解析实际字体用于Canvas，并随明暗和主题变化重新应用。
- 浅色是暖灰纸面、深墨文字和玉青强调；深色使用暗墨层次和低亮度强调。它有独立的字体、尺寸、排版和卡片呈现，不只更换颜色。

## 清晰现代修复

研究中心、市场主线与后续常规导航按钮统一尺寸、边框、底色与字体；数据源按钮保持协调。指数卡去掉260px宽度封顶，使指数条、导航和自选表格使用一致的页面边距。

手动“更新数据”入口保留，自动模型买卖、账户资金预设和后台任务不因切换主题改变。
