# 研究结论与资源边界

本目录用于确认哪些机制已经研究过，避免重复搜索同一历史和参数。`catalog.json` 保留32个研究目录的结论、参数和来源指纹；`compact-seed-verification.json` 记录当前模型与原历史分数逐股一致的验证。

当前程序保留六个预测器（五个原模型＋一个中位数预测器）、原均值双正确认定义、截止日评分向量，以及特征计算和增量校验所需的冻结行情与公司行动证据。原始行情目录不清理。失败实验、旧年度模型、完整历史评分矩阵不进入新安装包。

`cleanup.json` 和 `retired-artifacts.tsv.gz` 是本地旧实验缓存清理清单。自动审批拒绝批量删除，当前这批文件仍在本机，不能将计划字节数称为已经释放的空间。安装包已按独立的运行清单精简，不受本地缓存删除状态影响。

需要重新检验旧实验时，先核对假说、数据截止日期、失败原因和指纹；仅有新增数据或不同机制时再运行。摘要不等同于完整账本，文件指纹也不能替代来源或收益验证。

`release-v3.0.6-validation.json` 记录发布前的源码和独立安装验收；`public-release-v3.0.6-validation.json` 记录正式发布后的附件指纹、两平台 CI、公开便携包启动和六模型计算验收。六模型计算使用复制到独立测试目录的已保存在线行情，不代表全新安装能够补齐缺失的多年历史。
