# 提醒分类与悬浮窗调整

所有提醒记录、测试和开关统一放在主界面右下角“资讯与提醒”，收拢成6个主入口，同页的提醒仍分别控制。

- 市场资讯：资讯原文、手动解读和默认收起的“每日简报”。独立“资讯系统通知”开关关闭后仍采集和保存；每日简报单独控制生成，旧简报仍可查看。
- 市场主线：发现与观察变化，独立于资讯和研究中心。
- 研究中心：模拟买卖、模型条件、模型观察合在同一页，突出模拟买卖，其余放进默认收起的“其他研究提醒”。保留三个独立开关和记录类型标签。“盘中确认”整项删除：专用入口、证据页面、分钟条件节点与形态状态均移除，旧版相关提醒不再展示或恢复到重要悬浮窗。普通分时行情与图表照常使用。
- 行情与风险：只保留价格/涨跌幅与止损/止盈提醒及两个独立开关。
- 自动操作：只记录每日数据更新与重试、模型检查与建账、主线扫描完成、定时研究等后台任务的执行时间和结果。排除资讯采集、模拟交易状态、条件监控和所有提醒的重复抄录；不再记录扫描的中间进度，建账结果只记一次。数据更新失败、重试及当日重试停止统一跟随“记录自动操作”，取消独立异常开关和系统/悬浮通知；旧版数据异常归档在本页折叠查看。
- 悬浮提醒：集中设置重要提醒窗口及普通通知通道。

移除“本次提醒”和混合“研究归档”入口。研究中心和设置页只提供跳转“资讯与提醒”的入口，不再重复放开关。逐票规则和账户自动运行设置保留各自原入口；提醒开关不暂停研究中心自动账户。

重要操作提醒使用独立置顶窗口 important-alerts，复用 toast.html 入口，绕过资讯桌面弹窗队列。包含主线、模拟买卖、模型条件、行情和风险；逐条显示、手动确认，无自动消失计时。未确认记录保存在本地设置表，重启恢复。最多100条未确认，满时不删除旧条目，新提示转用系统与普通桌面通道，并保留分类归档。

重要提醒默认只显示独立窗口，可选择同时发送 Windows 系统通知。文字、背景颜色和透明度独立设置。两个悬浮窗都可拖动、右下角缩放，保存位置与尺寸；缩放按钮还支持方向键微调。行情窗手动尺寸优先，超出区域可滚动。行情窗右侧为自选和拉伸分别预留空间，手柄扩大为22×22像素，列表独立滚动，两个操作热区在最小尺寸下也不重叠；键盘焦点显示自选按钮，方向键缩放不会触发主界面。

新增各类提醒开关第一次启动时继承原研究提醒的静音选择，风险提醒继承旧行情提醒选择；后续互相独立。旧 research_notifications_enabled 仅控制“模型观察”，不再作为研究总开关。

## 验证

2026-10-09 收尾：前端生产构建与7项分类、历史和条件恢复测试通过；Rust 库测试427项通过、40项按既有标记跳过。隔离浏览器使用模拟记录检查各分类只显示对应内容、主线开关不影响模拟买卖、透明度更新、查看证据不自动确认、逐条确认不会移除其他提醒。浏览器还检查了160×32、230×38、320×64尺寸下的热区不重叠，多行滚动不移动手柄，以及自选、拉伸和方向键缩放只触发对应操作。验收不读取真实账户，不运行交易。

原生 Windows 拖动、缩放和系统横幅的实际显示仍需在桌面程序中验收。本次提供本地测试 EXE，不推送、不创建版本标签，由另一个窗口负责正式发布。
