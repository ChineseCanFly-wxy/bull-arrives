# 提醒分类与悬浮窗调整

所有提醒记录、测试和开关统一放在主界面右下角“资讯与提醒”，每类分别点击和控制。

- 市场资讯：只有资讯原文和手动解读，增加独立“资讯系统通知”开关，关闭系统通知仍采集和保存。
- 市场主线：发现与观察变化，独立于资讯和研究中心。
- 模拟买卖：研究中心跟随账户的委托、成交和拒单。
- 模型条件、盘中确认、模型观察：分别显示对应研究记录，各有开关。
- 行情提醒、风险提醒、数据更新：分别控制和查看。
- 每日简报：独立控制生成；旧简报仍可查看。
- 自动操作：只监控研究中心、主线和相关数据任务，排除资讯采集。
- 悬浮提醒：集中设置重要提醒窗口及普通通知通道。

移除“本次提醒”和混合“研究归档”入口。研究中心和设置页只提供跳转“资讯与提醒”的入口，不再重复放开关。逐票规则和账户自动运行设置保留各自原入口；提醒开关不暂停研究中心自动账户。

重要操作提醒使用独立置顶窗口 important-alerts，复用 toast.html 入口，绕过资讯桌面弹窗队列。包含主线、模拟买卖、模型条件、盘中确认、行情和风险；逐条显示、手动确认，无自动消失计时。未确认记录保存在本地设置表，重启恢复。最多100条未确认，满时不删除旧条目，新提示转用系统与普通桌面通道，并保留分类归档。

重要提醒默认只显示独立窗口，可选择同时发送 Windows 系统通知。文字、背景颜色和透明度独立设置。两个悬浮窗都可拖动、右下角缩放，保存位置与尺寸；缩放按钮还支持方向键微调。行情窗手动尺寸优先，超出区域可滚动。

新增各类提醒开关第一次启动时继承原研究提醒的静音选择，风险提醒继承旧行情提醒选择；后续互相独立。旧 research_notifications_enabled 仅控制“模型观察”，不再作为研究总开关。

## 验证

前端生产构建、分类与历史测试通过；Rust 库测试通过。隔离浏览器使用模拟记录检查各分类只显示对应内容、主线开关不影响模拟买卖、透明度更新、查看证据不自动确认、逐条确认不会移除其他提醒。浏览器验收不读取真实账户，不运行交易。

原生 Windows 拖动、缩放和系统横幅的实际显示仍需在桌面程序中验收。本次不发包、不推送、不创建版本标签，由另一个窗口负责发布。
