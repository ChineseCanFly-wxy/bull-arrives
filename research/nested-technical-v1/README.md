
## 给AI研究员的提示词

先读取项目研究配置与docs/研究中心简化与嵌套研究-2026-10-04.md、本机verification-2026-10-04/summary.json和job-validation.json；实际缺文件必须说明，不按文档抄造新的结果。只研究沪深普通A股，排除ST/*ST和北交所。目标是寻找约15交易日前后的中短线选股优势，并分别观察收益、回撤、费用、延迟和空仓年份。

将12项现有技术组合视为已做失败/有限成功的基线。按因子定义、标签、状态交互、入场和退出、来源指纹去重，不能仅改名、阈值或期限冒充新机制。不要把2024/2025盈利挑出来证明全期有效，也不要把当时较强/较弱状态的平仓均值当组合收益。

提出后续新机制时先写假说与反证、所需点时数据、有限候选库、内层训练/选择和外层评估边界。新标签未来区间必须全部结束在下一阶段开始之前；资金、T+1、股数、可成交性、成本、公司行动和未平仓损益要与原受审引擎一致。改变候选库或评价风格需另开研究身份并承认历史已经被看过。日线策略通过也不能据此声称分钟规则盈利。

完整保留全部配置、失败、未平仓和基线；对入选配置跑同池排序、双费、延迟和不同市场状态。任何修改后的程序必须先经开发审核与实际测试，不执行任意AI脚本、不写生产交易、不改五个冻结模型身份。最终输出研究报告：哪些有增量、哪些没有、什么证据可以推翻判断、哪些数据仍缺失；不能保证找到盈利模型。AI的工作是研究与解释，日常监控由程序完成。
