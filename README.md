## 当前版本

当前版本为 **v3.0.3**（2026-10-09）。本版补齐跨电脑研究环境，近期主线观察直接获取在线行情，并整理独立提醒与悬浮窗；下载请认准 [Releases](https://github.com/ChineseCanFly-wxy/bull-arrives/releases) 中非草稿、非预发布的版本。

### v3.0.3 更新

- **安装即带研究环境**：安装包和便携包包含私有Python、锁定依赖、研究脚本、冻结快照与模型。默认自动定位并修复失效的旧构建路径；StockDB仍由用户单独安装。

- **个股模型与形态研究**：模型证据卡、近期资讯原文、模型与反证解读放在同一入口；模型分数和 AI 确定性均不等于上涨概率。
- **技术组合研究**：固定12项候选，按历史顺序训练、选择和评估，记录市场状态、费用/延迟及同池排序；五年92份实际账户结果保留，当前未新增准入模型。见[本轮验收](docs/研究中心简化与嵌套研究-2026-10-04.md)。

  换 trading / modern 后这些样式直接失效；统一改为 `html[data-style="…"]`

## 🔍 选股与量化

> 四大模块 + 一套重写过的数据层：全市场筛选器 / 推荐榜 / 个股量化评分与价格位 / 智能监控。

### 🔎 市场筛选

沪深普通股行情筛选，固定排除 ST、退市、北交所及 B 股：

- **明确的页面切换** —— 市场筛选与研究模型使用有当前标记的分段导航，记住上次页签。顶部切换、查询与关闭按钮、底部分页一直可见。
- **手动查询** —— 首次默认不限条件，后续恢复上次条件。选择“不限条件 / 流动性优先 / 今日活跃 / 温和上涨”只应用条件，点击查询才读取行情。
- **自定义条件管理** —— 价格、市值、成交额、换手率、涨跌幅及更多估值条件自由组合；行业、概念支持多选。条件可命名保存、覆盖、改名、删除。新的行情条件独立保存，旧研究策略不会自动恢复执行。
- **结果与条件对应** —— 条件调整后显示待查询；现有结果和翻页继续使用上次已提交条件，直到重新查询。
- **行业、概念和手动分析** —— 表格展示行情通道提供的分类，缺失时说明来源；每行可打开分析、查看走势、加入自选。AI 仅由用户点击生成。
- **按需量化排名** —— 默认未评分。可计算本页，或分批计算当前命中的全部股票并按同日技术状态分排名。显示进度、失败与日期边界，可停止；缺失/陈旧/异日数据不冒充当前分数。
- **数据源和分页** —— 自动 / 东方财富 / 新浪财经。更多条件中可调整每页数量，点击查询后生效；数据源不支持的条件会明确提示。

“研究模型”页现在可直接选择全部5项或单项冻结模型，点击“筛选符合条件的股票”推断最近完成日信号。各模型独立排名，行内支持分析、走势、自选和组合条件观察；任务可关闭页面后继续，应用退出后可续跑。观察时可同时开启原模型盘后更新，触发时证据保存在提醒记录。五项仍为研究模型，均未实盘准入。

技术状态评分与行情预设用于研究观察，不能视作经验证的盈利策略。冻结模型的真实收益标签与多年组合证据在独立的“研究模型”页查看。

### 🏆 推荐榜

从最活跃的一批股票里，按**多因子加权评分**排出 Top 榜单，一键加自选或查看深度分析。

### 📊 个股模型与形态研究

打开分析先显示零至一百的技术状态分与简短模型观点，详细内容按需展开。评分计算使用现有趋势、量能、动量、RSI 极值因子；分数不等于上涨概率。

- **模型证据与近期原文** —— 核对个股同日评分、冻结版本、多阶段收益、回撤与双成本表现，原文同时标注公开与采集时间。
- **手动 AI 解读** —— 点击生成才调用 Claude，解释当前观点、支持证据、等待条件与最强反证。每条判断附快照字段、数值与日期；可以继续针对性提问并查看真实输入和调用记录。
- **技术形态与规则对照** —— 趋势跟随、均值回归、放量突破用于描述当前形态和价格情景，可自动匹配或手动切换。界面明确区分本股回放门禁与多年、多股组合验证，三条规则未获多年盈利准入。
- **本股规则回放** —— 展示实际样本、收益、成本、回撤、因果检查和具体门禁原因；仅限本股数据证据，不自动选择历史收益最高的规则。
- **价格位与因子明细** —— 支撑压力、规则价位、因子说明和指标快照均可展开核对。简短问号说明使用悬停/键盘提示。

当前冻结模型仍为研究观察，未获得生产或实盘准入。具体步骤见 [日常使用指南](docs/日常使用指南.md)。

### 🎯 智能监控

在自选股上开启监控后，**不用再手动填止损止盈价** —— 程序按 ATR（真实波幅均值）自动计算合理位置并盯盘提醒。

- **可以随时停止 / 恢复** —— 停止只翻开关：止损止盈位、触发状态全部留着，恢复后按原价位继续判断。
  与「删除」是两件事（删除才是真的不再监控）。**「刷新」重算价位不会把停掉的监控悄悄打开**
- **可以删除** —— 自选股右键菜单与「持仓监控」里都能删。自选股表的「监控」列直接显示
  **监控中 / 已停止 / 已止损 / 已止盈**，右键菜单按当前状态给出 开启 / 停止·恢复 / 删除监控
- **「持仓监控」是统一的监控管理页** —— 顶部输入代码或名称即可搜全市场添加（不输入时下拉里是自选股），
  支持关键词筛选与「全部 / 监控中 / 已停止」切换，每行可就地 停止|恢复 · 刷新 · 删除

### 🛡️ 数据层重写：多通道自动回退

真机实测发现单一数据源存在**间歇性阻断与 IP 限流**，因此数据层改为多通道：

| 数据 | 主力 | 兜底 |
|---|---|---|
| 全市场快照 | 东方财富（字段最全，含量比） | 新浪财经 |
| 日 K 线 | 腾讯财经（前复权） | 新浪财经 → 东方财富 |

通道故障自动降级并回传提示（如「当前数据源不提供量比，该条件已自动忽略」），**不再整页报错**。一字板判定按板块区分涨跌幅限制（主板 10% / 创业板科创板 20% / 北交所 30%），阈值统一取自 `market_rules`，与模拟撮合同源；**主板 ST / *ST 自 2026-07-06 起由 5% 放宽到 10%**，口径已同步，不会再把 ST 的普通波动误判成封板。

## 🆕 自选股与提醒

> 这一节是本仓库在原项目基础上的扩展：自选股分组、持仓、提醒体系与设置面板。

### 📁 自选股分组

自选股一多就乱？现在可以分组建管。

- 新建 / 重命名 / 删除分组，顶部工具栏一键切换
- **组内独立排序**，调整某组的顺序不影响其他组
- 股票可自由在组间移动
- **全局快捷键**循环切换分组（上/下一组，首尾环绕）

### 💼 持仓管理

不只是看行情，还能盯自己的仓位。

- 录入**每股成本价**与**持仓股数**
- 实时计算**持仓市值**、**浮动盈亏**、**盈亏比例**，随行情自动刷新
- 持仓按股票保存、跨分组共享

### 🔔 行情提醒

不用一直盯着屏幕，到价了它会告诉你。

- **涨跌幅提醒** —— 按昨收价计算，设定阈值（如 `+5%` 提示、`-5%` 预警）
- **固定价格提醒** —— 设定目标价，**向上穿越**或**向下穿越**时触发
- **三种重复方式** —— 每日一次 / 重新穿越 / 冷却间隔（1–1440 分钟）
- 每只股票可独立配置，规则可暂停而不删除

### 🪟 桌面提醒窗

独立于主窗口的提醒窗口，不打断你手头的事。

- **始终置顶**、无边框、不占任务栏
- 多条提醒**自动排队**，逐条展示不堆叠
- 点击提醒**直接跳转主窗口**
- 主窗口关着也能收到（托盘常驻）

### 📜 提醒记录

错过的提醒，回头还能查。

- 记录标题、正文、时间以及系统/桌面通道状态
- 保留本次运行最近 50 条，可一键清空
- 清空只影响展示历史，不会重置规则状态

### ⚙️ 偏好设置面板

原本散落在各处的设置项，现在集中管理。

- **行情** —— 刷新间隔（自动 / 1–60 秒固定）、本地历史数据连接与行情源选择；
  下方直接显示**交易日历的覆盖区间与来源**（指数行情推断 / 公告兜底），推断不出就明确提示
- **提醒** —— 总开关、通知身份注册、桌面兜底、测试通知
- **悬浮窗** —— 分组快捷键、显隐快捷键、**透明度**、**单色显示**、字体颜色（带外观预览）
- **外观** —— **界面风格**（原版 / 清晰现代）与**明暗模式**分开选，各自动保存、下次启动恢复
- **Agent** —— 可执行文件与工作目录、超时、**后台单次预算**（0.05–10 美元，只管后台调用）
- **系统** —— 开机自启、运行模式、**主窗口打开大小**，并显示**数据目录与设置数据库的实际路径**

保存语义也分清楚了：**开关类改动即时自动保存**；路径、超时、预算这类需要手输的，点对应按钮才落库。
保存过程中不允许关闭设置窗，有未保存的改动时会先提示确认。

## ⚡ 性能

### 启动即见行情

行情数据实时写入本地缓存，应用启动时**直接读取缓存渲染界面** —— 打开就能看到上次的报价，不必先等网络请求返回，数据到了再静默刷新。

### 只看你关心的，不多请求一条

**这是本版本相比原版最明显的差异。**

分组之后，程序**只请求当前分组**中的股票：

| 场景 | 原版 | 本版本 |
|---|---|---|
| 自选 200 只，此刻只看其中 10 只 | 轮询全部 200 只 | 只轮询当前分组的 10 只 |

自选股越多、分组越细，省下的请求量与带宽越可观 —— 换来更少的等待、更低的资源占用，以及更清爽的行情刷新。

### 不交易就不打扰

- **自适应轮询** —— 开盘快速探测确认活跃度，连续无变化自动降到约 30 秒
- **交易时段感知** —— 盘前约 5 秒 / 午休约 10 秒 / 休市约 30 秒，节假日智能休眠
- **请求时段外完全静默** —— 可选的时间限制开关，开启后时段外不发起任何网络行情请求，已有缓存照常显示（默认关闭，全天获取 + 自动降频）

### 刷新不打断操作

- 分时图**增量更新**，曲线平滑延伸，不整图重绘、不闪烁
- 五档盘口 3 秒静默刷新，不干扰你正在进行的操作
- 图表按周期采用不同刷新节奏（分时 5s / 日 K 30s / 周月 K 60s）

## 🌟 特色功能

### 🤖 本地 Agent 解读（Claude Code）

把量化快照交给**你本机已装的 Claude Code** 去解读，而不是让应用自己去连模型：

- ✅ **不直连模型、不管理密钥** —— 应用不存也不读任何 API Key，也不维护第二套模型配置，
  直接复用你本机已有的 agent 能力
- ✅ **权限显式收敛** —— 不使用跳过权限模式（有测试守着）、工作目录隔离、
  **不读取也不改动**你的全局配置；固定单并发、超时可配（默认 90 秒，可设 15–300 秒）、
  可中断并回收整个进程树
- ✅ **可见的 Agent 工作台** —— 设置里就能探测本机安装位置、**主动测试连接**，
  并区分「找到安装文件」与「真的连上了」；快照失败时给出重新分析的指引，
  不再把你往登录 / 网络方向带偏
- ✅ **快照指纹修好了** —— 之前会误报「Agent 冻结快照指纹校验失败」：
  根因是 JSON 未启用精确浮点往返，高精度小数序列化再反序列化后数值位模式发生变化，
  重新计算的 SHA-256 就对不上了。修复后指纹稳定，**改数据的篡改用例依旧会失败**
- ✅ **诊断输出不外泄** —— 持续读取 CLI 输出，只在内存里保留有界尾部并返回固定分类提示；
  原始输出**不写日志、不落文件、不上界面**
- ✅ **两个入口** —— 单次单角色解读，以及多子代理团队分析（技术 / 资金 / 资讯等角色各跑一个进程再汇总）；
  两个入口不能同时跑，中止后不再启动后续角色，**风控失败也不会拿别人的意见充当最终结论**
- ✅ **交互终端：直接打开来聊** —— 除了「跑完给一份结论」，还可以把会话开在界面上：边跑边看事件流，
  随时**追问**、中途**取消**、关掉窗口后按任务 id **接回**同一个会话，上下文不丢。
  这条链路由你直接操作，**不套用后台那次 90 秒超时，也不占用单次预算**；
  手动触发的后台任务（个股解读 / 多角色研判 / 资讯摘要 / 动态筛选）仍受预算约束；资讯不自动生成 AI 解读
- ✅ **提示词外置** —— 基础 / 单股 / 技术 / 多方 / 空方 / 风控 / 资讯 / 连接 / 筛选 / 策略发现
  都在 `src-tauri/prompts/*.md`，改词不用改代码
- ✅ **预测会算总账** —— 每次预测落库，次日自动比对给出真实校准曲线，不靠"感觉准"
- ✅ **失败就退回去** —— 检测不到可执行文件时给明确指引；agent 失败只保留纯量化结果，不编结论

### 🔬 研究中心：从想法到前向证据

把一个想法推到有前向证据的全过程记录下来。新增模型研究只研究沪深普通 A 股、排除 ST 与北交所；下面的原有模拟账户仍按独立规则运行。模型观察不等于实战准入。

- ✅ **候选 → 观察 → 采纳** —— 完整台账；**研究实验的采纳与原有实战准入相互独立**，
  研究跑得通不代表实战验收通过
- ✅ **三种执行方式，账本各自独立** —— **实时前向**（默认，用委托建立**之后**收到的新鲜报价与
  对手盘口成交）／**日线前向**（已完成的日线信号，之后交易日按开盘价成交）／
  **并行对照**（同一候选建两个独立账户各按自己的口径跑，主考核看实时账户）。
  资金、订单、净值、回撤与样本**完全不合并**，不合并胜率、也不挑好的那边冒充整体成绩
- ✅ **实时口径从严** —— 买入参考卖一、卖出参考买一，**滑点后价格不得突破限价**；
  最优档可见量不足就**整笔等待**，不虚构排队成交与部分成交；委托当时的旧报价不能成交；
  当天未成交的限价委托直接过期，**不拿次日开盘或当天高低点事后补成交**
- ✅ **只交易 A 股** —— 代码限定沪深北股票，拒绝港美股、基金、债券与指数；时钟统一按北京时间

### 📈 模拟账户与胜率测算

用来回答「**我做出来的策略，胜率到底如何**」，全程自动：

- ✅ **独立账户** —— 与真实持仓数据完全分开，不下真实单、不接券商接口
- ✅ **撮合按 A 股规则** —— **涨跌幅与申报单位按代码所属板块自动判定**
  （主板 ±10%，含 2026-07-06 起并轨的主板 ST/*ST；创业板·科创板 ±20%；北交所 ±30%；
  科创板 200 股起、北交所 100 股起，超出部分 1 股递增，其余 100 股整手），
  **账户里配错的涨跌幅参数不会改变撮合结果**；退市整理期与上市未满 5 个交易日的股票不参与模拟
- ✅ **涨跌停怎么判** —— 停牌、**T+1 可用持仓**、可用资金不足都会被拦；
  以涨停 / 跌停价开盘但**盘中开板**（当日有振幅）的仍按开板价撮合，
  只有全天振幅为 0 的**一字板**才拒单
- ✅ **交易日历自己识别** —— 由上证指数日 K 与盘中实时报价推断，**跨年自动滚动**，
  不需要每年手工录入交易所休市日；行情完全不可用时才回退到公告日历，且明确报错而不是猜
- ✅ **成本可配** —— 手续费 / 印花税 / 过户费集中在配置里，不是写死的常数
- ✅ **只认未复权价** —— 本地历史库只有前复权 K 线时，自动任务**只生成指令、不改账本**；
  用复权价撮合会把涨跌停判定和成本一起算错
- ✅ **每笔都有出处** —— 记下触发来源（哪条策略 / 规则 / AI / 手动），否则事后答不出数字是谁跑出来的

### 🗂️ 本地历史数据（stockdb）

把长周期历史行情交给**你自己的本机数据库**，零网络、零限流：

- ✅ **默认关闭** —— 不开就完全不启动、不探测、不读取 stockdb；实时行情、盘口、监控、提醒
  一律不受影响
- ✅ **自动管理** —— 设置里选一次引擎（自动扫描候选，也可以手动浏览选 `stockdb.exe` 与
  `数据更新.exe`），之后**随应用启动自动拉起**；关到托盘不停，真正退出时才关闭
- ✅ **只碰自己的进程** —— 只管理**由它启动的**实例。你要是已经手工启动了服务，
  它直接用，但**不接管、也不结束**你的进程
- ✅ **不会弹浏览器 / 托盘** —— 拉起时固定带 `-d`（free-stockdb 官方选项 `-d: run as daemon`），
  以 daemon 方式在后台跑；不带这个参数它会走桌面模式、用 `ShellExecuteA` 打开自己的网页
  并挂一个托盘图标。应用只需要它的 HTTP 服务，所以**任何启动路径都不绕过 daemon 模式**
  （有单测守着，见 `stockdb::tests::engine_is_always_started_as_daemon`）
- ✅ **顶栏一键更新** —— 「更新本地数据」会先停掉自己启动的 stockdb → 弹出原生
  `数据更新.exe` 窗口 → 更新程序退出后自动把服务拉回来；更新期间从托盘退出会被拦下并提示等待
- ✅ **不可用时会说清楚** —— 单股分析回退在线短区间，并在结果里标明**来源与样本数**；
  推荐榜与批量筛选仍走全市场快照，**不会退化成逐只在线拉历史**（那样必被限流）
- ⚠️ 当前**只有 Windows** 支持自动管理；引擎是外部程序，**不含在安装包里**

引擎是 [hello245m/free-stockdb](https://github.com/hello245m/free-stockdb)（MIT）——
面向 A 股日K、分钟K 与 ETF 分钟数据的本地量化引擎，集成增量同步、本地缓存、复权、
批量查询、回测与指标计算。

### 🖱️ 可拖拽的浮动行情条

桌面右下角常驻一个迷你行情条（默认 230 × 38）：

- ✅ **始终置顶**在所有窗口之上，无边框、不占任务栏
- ✅ **两种展示模式** —— **轮播**（每 3 秒翻页，数量 1–20 只可选）或**自适应全显**（增删当前分组自选时自动调整高度，超过屏幕可用高度时滚动）

- ✅ **鼠标悬停暂停**，方便仔细看某只

行情自动写入本地缓存，重启时立即恢复上次报价。

### 🔄 应用内自动更新

Windows / macOS 安装版支持**应用内自动更新** —— 发现新版本后按提示下载安装即可，无需手动去 GitHub 下载。交易时段内启动检查不会弹出提示，避免打断看盘。

放置一个 `portable.dat` 到 exe 同级目录即进入便携模式：所有数据（数据库、日志）写入同级 `data/`，不碰系统 `%APPDATA%`，适合 U 盘携带或多版本并存。

本项目的**本地历史数据**能力对接 [hello245m/free-stockdb](https://github.com/hello245m/free-stockdb) —— 面向 A 股日K、分钟K 与 ETF 分钟数据的本地量化引擎，集成增量同步、本地缓存、复权、批量查询、回测与指标计算。感谢原作者 **[hello245m](https://github.com/hello245m)** 开源，该项目以 **MIT 许可证**发布。

需要说明的是，该引擎是**独立运行在你本机的服务**：本仓库不分发它的任何代码或数据，只是把长周期历史行情接进来用；是否启用由你决定，数据版权、使用授权与再分发条件请自行向其仓库确认。
